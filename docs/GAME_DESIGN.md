# Game Design

## Secret Director
4–8명 모두 Ready → 각자 서로 다른 미션 → 8분 자유 채팅 → 중간 1–2회 Twist → 제한시간 종료 → 다른 사람의 미션 추측/투표 → 모든 미션 공개 → 결과/MVP/명장면 → 재게임.

예시 미션: 다른 사람이 “진짜?”라고 말하게 하기, 한 사람의 의견에 자연스럽게 세 번 반대하기, 대화를 특정 가벼운 주제로 돌리기. 사생활 고백을 요구하는 미션은 초기 풀에서 제외한다.
재미는 비대칭 정보, 몰래 이상한 행동, 의심, 마지막 Reveal에 있다. 미션을 수행하느라 대화가 부자연스러워지는 정도를 실험한다.
명시적 단어/횟수는 규칙으로, 맥락은 증거와 함께 AI가 검토한다. 불확실한 성공을 단정하지 않는다. MVP는 별도 평가이며 추측 투표로 미션 성공을 확정하지 않는다.

## Everybody Knows Except You
4–8명 중 대상 한 명을 서버가 선정 → 다른 모두에게 같은 비밀 규칙 → 자유 채팅/필요 시 비공개 추가 지시 → 대상이 상황 추리 → Reveal/요약.

예시: 대상이 컵 이야기를 하면 모두 갑자기 칭찬한다. 대상에게는 일반 진행 안내만 전달하고 공유 규칙은 전달하지 않는다. 공개 이벤트에 그 규칙을 넣지 않는다.
집단의 가벼운 연기와 사회적 오해를 즐기되 한 사람을 소외시키는 경험은 피한다. 이후 재게임에서 대상 순환 정책을 검증한다.

## 공통 원칙
- 규칙 설명은 짧게, 사람들끼리 대화하는 시간을 길게.
- 미션은 자연스럽고 관찰 가능해야 한다.
- 끝나면 비밀을 납득할 수 있게 공개한다.
- 성공률보다 웃긴 순간과 재게임 의향을 먼저 본다.
- AI 개입으로 대화가 끊기면 개입을 줄인다.

## 실험 후보 — 구현 약속 아님
라운드 5분/8분, 이벤트 1회/2회, 자유 추측/선택지 투표, 개인 미션 난이도, Everybody 대상 순환. 새 포맷은 두 게임으로 재미를 확인한 이후 고려한다.

## 현재 구현 수준
각 src/games 폴더의 index.ts에 설정/규칙/프롬프트 맥락/phase/결과 정책만 모았다. 실제 배정, 타이머, 채팅, 투표, Reveal, 판정은 아직 없다. 파일 분리는 내용이 커질 때 한다.
