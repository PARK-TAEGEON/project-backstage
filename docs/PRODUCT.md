# Product

## 핵심 가설
친구 4–8명이 같은 방에 들어와 AI 때문에 웃긴 상황이 발생한다. 검증 질문은 “채팅만으로 게임이 실제로 재미있는가?”다.

## 타깃 경험
친구끼리 링크/코드로 모이고, 닉네임만 정한 뒤 8분가량 대화한다. 이상한 행동을 눈치채고 마지막 Reveal에서 함께 웃는다. 8분은 최초 실험값이며 고정된 제품 약속이 아니다.

## 인간 90 / AI 10
AI는 등장인물보다 제작진이다. Director는 진행과 이벤트, Mission Designer는 개인 지시, Referee는 판정, Social Analyst는 대화의 흐름, Editor는 마지막 명장면을 담당한다. 역할은 논리적 책임이며 독립 AI 캐릭터나 상시 실행 에이전트를 뜻하지 않는다.

사람의 대화를 방해하지 않는다. 시작 시 미션, 중간 1–2회 이벤트, 필요한 묶음 판정, 마지막 요약에만 개입한다. AI 호출량 자체보다 인간 대화가 살아 있는지를 본다.

## 초기 포맷
- Secret Director: 각자 다른 비밀 미션 → 자유 채팅 → 서로 추측/투표 → 미션 공개 → 결과.
- Everybody Knows Except You: 한 명만 모르는 공통 규칙 → 함께 반응 → 대상의 추리 → Reveal.

## 목표 흐름
Home → Create/Join → Nickname → Lobby → Ready → Game → Guess → Reveal → Results → Play Again.
로그인을 강제하지 않는다. 향후 Supabase anonymous auth로 내부 식별을 처리한다. 모바일 브라우저를 우선 지원한다.

## 하지 않을 것
아바타, 캐릭터 이동, 가상 공간, 코디, 아이템, 친구 시스템, 소셜 피드, 길드/클럽, 랭킹, 복잡한 계정, 모바일 네이티브 앱, 음성/영상 채팅, 여러 AI 캐릭터, 복잡한 메타게임, 과금.

## 재미의 경계
비밀 규칙은 가벼운 오해를 만든다. 민감한 경험 고백, 원치 않는 사생활 노출, 특정인 모욕은 미션으로 요구하지 않는다. 이후 실제 게임에서는 중단/나가기와 편하지 않은 미션 교체를 고려한다.

## 초기 지표
완주율, 종료 직후 재게임 의향/클릭, 초대 링크 복사, 결과 공유를 관찰한다. 로그와 참가자의 실제 웃음/인터뷰를 함께 본다. 아직 플레이테스트 데이터는 없다.
