# 현재 상태 / 문서의 근거

## 30초 요약
Project Backstage는 **사람들이 함께 놀고 웃는 채팅 기반 소셜 파티게임을 빠르게 실험하는 웹 프로젝트**다. 사람은 출연자, AI는 필요한 순간에 개입하는 제작진이다. AI 없는 게임도 허용한다. Claude가 오케스트레이터를 맡는다.

현재 명시된 방향:
- MVP는 채팅 기반. 플랫폼 전체를 먼저 만들지 않는다.
- 낯선 사람 / 친구 관계와 짧은 / 중간 / 긴 플레이를 분류한다.
- 모든 게임은 관계, 길이, AI 개입, 최소/권장/최대 인원을 갖는다. 최소 3명 플레이를 허용한다.
- 아이디어는 대량 수집할 수 있으나 그대로 채택하지 않는다. ASTRA(치명 문제) → 실제 사람 테스트로 걸러낸다 (DEC-13).
- 카탈로그는 추가·삭제·수정을 계속하는 문서다. 원대화의 대량 목록은 승인된 콘텐츠가 아니다.
- 웹, 아바타/코디, 소셜, Roblox, 포맷 라이브러리는 장기 가능성이다.

## 출처와 범위
[사업 아이템 발굴](chatgpt-conversation://6abab090-0a64-83e9-b46a-2149fc5c1f4a)의 Work 인계 프롬프트와 그 이후 대화를 중심으로 압축했다. 아바타/코디·소셜 확장만 인계 직전 사용자 발언을 함께 확인했다. 현재 사용자 요청을 최종 기준으로 삼는다.

주요 근거:
- Work 인계: Claude 오케스트레이터, 웹 실험, 최소 공통 엔진, AI 제작진, 초기 후보와 기술 제안.
- 이후 사용자: 웹과 Roblox 병행 가능성, 채팅 미니게임 다양화, 로비 조건 분류.
- 이후 사용자: 대량 추가 후 ASTRA → FABLE → 실제 사람 리뷰; 저품질 아이디어 직접 검수 필요.
- 최종 보정: 최소 인원 3명 허용, 정해진 분류를 항상 유지, 카탈로그 지속 관리.

과거 assistant가 제안한 게임 수 1/2/6/30개, 시간 구간, 최대 인원, 스택은 확정 사실로 승격하지 않는다. “5~10개만 생성”이라는 과거 assistant 제안보다 현재 사용자의 **대량 생성 후 검수**를 따른다. 시장 통계와 경쟁사 평가는 이 문서의 근거에서 제외했다.
