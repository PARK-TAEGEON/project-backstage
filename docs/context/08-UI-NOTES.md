# 8. UI 참고 메모

UI를 만들 때 참고할 사용자 요청과 게임 스펙에서 나온 공통 화면 요소. 디자인 확정안이 아니라 **요구 사항 메모**다. 게임별 세부는 각 스펙이 원본이다.

## 전광판 [확정 — 사용자 요청, 2026-09-29]
- 게임이 바뀔 때마다 **전광판** 같은 화면을 띄우고, 그 위에 **게임 이름·주제를 크게** 올린다.
- 목적: 다음 게임으로 넘어가는 순간을 이벤트로 만들고, 지금 무슨 게임인지 한눈에 알게 한다.
- [제안] 전광판에 한 줄 규칙을 함께 띄운다 (예: “같은 숫자 겹치면 탈락!”). 설명 30초 목표(04-CATALOG-POLICY)와 연결.
- [제안] 전광판은 게임 중 발표 연출에도 재사용한다 — 포브스 “포브스 선정 ○○ 1위”, 눈치게임 “오늘의 눈치 없는 사람”, 쿵쿵따 최종 생존자.

## 방 만들기·대기실 [확정 — 사용자 요청, 2026-09-29]
- 방 만들기 버튼을 누르면 **작은 팝업**에서 방 규칙(최대 인원, 방 라운드, 게임 순서, 등장 게임)을 정하고 만든다.
- 대기실에 **코드 복사**와 **초대 링크 복사** 버튼을 둔다.
- 게임 내부 규칙(라운드 수 등)은 방 설정에 보이지 않는다 (DEC-15).
- **Roblox 후보 같은 내부 참고 정보는 플레이어 화면에 보이지 않는다.** 관리자 화면(/admin)에만 표시한다.
- 첫 화면에는 로고와 PRESS START만 두고 설명 문장은 넣지 않는다.

## 중앙 카운트다운
- 화면 중앙에 크게 **3 · 2 · 1**. 눈치게임에서 확정, 다른 게임의 라운드 시작에도 쓸 수 있는 공통 부품.

## 게임별로 이미 정해진 UI 요소
| 게임 | 요소 |
|---|---|
| 단어 말하기 | 개인 화면의 비밀 단어, 플레이어 클릭 → 단어 입력 챌린지 |
| 금지어 | 남의 금지어는 보이고 내 것만 가려진 표시, 입막힘 표시 “🤐”, 걸린 순간 챌린지 입력(10초) |
| 쿵쿵따 | 단어 전용 입력칸 + 자유 채팅, 비트·효과음(실험), 음소거 버튼 |
| 포브스 | 10초 지목 투표, 당선 발표 |
| 눈치게임 | 중앙 카운트다운, 동시 판정 시간 차 표시(제안) |

## 폰트 [확정 — 사용자 요청, 2026-09-29]
콘셉트: 전자오락실. 두 폰트를 섞는다. 둘 다 SIL OFL 1.1이라 상업적 사용·웹 임베드가 무료다.

| 용도 | 폰트 | 적용 위치 | 로드 방식 |
|---|---|---|---|
| 큰 제목 | Black Han Sans | 전광판 제목, 로고, 방 코드, 큰 숫자 | Google Fonts |
| 오락실 도트 | Galmuri11 (갈무리, quiple) | 배지, 라벨, 카드 제목, 점수·숫자, 타이머, 채팅 알림, 전광판 윗줄, PRESS START | 저장소에 포함 (`apps/web/src/assets/fonts/galmuri/`, 라이선스 동봉) |
| 본문 | Noto Sans KR | 채팅, 설명, 입력칸 | Google Fonts |

- 도트 폰트는 12px 배수(12·24px)에서 가장 선명하다. 토큰 `--font-pixel`, `--fs-pixel`, `--fs-pixel-lg`.
- 긴 문장·입력에는 도트 폰트를 쓰지 않는다 (가독성).

## 설명 문구 최소화 [확정 — 사용자 요청, 2026-09-30]
- **화면에 자잘한 설명 문구를 넣지 않는다.** 예: “득점은 나만 알아요…”, “남의 금지어를 말하는 건 괜찮아요 — 들키면 손해일 뿐”, 단어 풀 설명(“입버릇 단어 — …”).
- 규칙 설명은 전광판 한 줄로 충분하다. 게임 화면에는 상태(단어·점수·남은 시간·순위)와 버튼만 둔다. 꼭 필요한 선택지는 짧게 (예: “맞히면 +3 · 틀리면 −3”).
- 새 화면을 만들 때도 이 원칙을 따른다.

## 사회자 대사 [확정 — 사용자 요청, 2026-09-30]
- 사회자(물꼬 트기) 대사는 채팅에서 **굵고 크게** 보인다 (채팅 메시지 종류 `host`).

## 라운드 순위표 [확정 — 사용자 요청, 2026-09-30]
- 여러 라운드인 점수 게임(단어 말하기·금지어)은 라운드 공개 때 **[현재 순위]** 표를 보여 준다: 순위, 이름, 이번 라운드 획득 점수, 게임 누적 점수.

## 공통 원칙
- 모바일 브라우저 우선 (02-DEVELOPMENT-MVP).
- 소리가 나는 게임은 음소거 버튼 필수, 모바일은 첫 터치(Ready) 때 오디오를 켠다.
