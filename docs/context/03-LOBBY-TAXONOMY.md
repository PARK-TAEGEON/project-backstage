# 3. 로비 생성 / 게임 분류 체계

**확정:** 후보·보류·채택 여부와 무관하게 모든 등록 게임은 다음 분류를 항상 갖는다.

| 필드 | 허용 값 / 형태 | 의미 |
|---|---|---|
| mode | individual / team / asymmetric_team 중 하나 | 개인전 / 팀전 / 비대칭 팀전. 게임 단위로 고정 (DEC-03) |
| relationship | stranger / friends / both 중 하나 | 사전 관계가 필요한지 |
| length | short / medium / long 중 하나 | 해당 변형의 플레이 길이 |
| ai_intervention | none / low / high 중 하나 | 플레이 경험에 필요한 AI 개입 |
| min_players | 3 이상의 정수 | 규칙이 성립하는 최소 인원 |
| recommended_players | 권장 인원 목록, 예: [4,5,6] | 재미와 흐름이 적합하다고 예상/검증된 인원 |
| max_players | min_players 이상 정수 | 지원하는 최대 인원 |

코드에서는 위 필드에 더해 다음 두 가지를 `GameMeta`(packages/shared/src/game.ts)에 둔다 (DEC-14).

| 필드 | 허용 값 | 의미 |
|---|---|---|
| inputs | chat / vote / text / avatar 중 여러 개 | 플레이 입력 방식. avatar는 추후 움직이는 아바타 게임용 |
| platforms | web / roblox | 실행 플랫폼. **`ai: none`인 게임만 Roblox 후보** (`isRobloxCandidate`) |

운영 규약: 개인전과 팀전이 모두 가능한 게임은 방식별로 **별도 항목**(예: `XXX-solo`, `XXX-team`)으로 등록하고 각각 분류·검수한다. 한 경기 안에서 라운드마다 방식을 바꾸지 않는다. 권장 목록은 비어 있지 않고 모든 값이 최소~최대 범위 안에 있어야 한다. 짝수 전용 등은 `player_constraints`로 추가한다. **3명 허용은 제품 방향이며 게임별 min을 억지로 3으로 낮추라는 뜻이 아니다.** 최대 8명은 원대화의 초기 범위 제안이고 영구 상한은 미정이다.

## 분류 해석
- stranger: 사전 지식 없이 시작할 수 있는 포맷. strangers에서 실제 작동했는지는 별도 검증한다.
- friends: 서로를 아는 맥락에 의존하는 포맷.
- both: 두 관계에서 성립하도록 설계한 포맷. 두 집단 검증 전에는 가설 태그다.
- none: 해당 플레이 경로에 런타임 AI가 필요하지 않다. 미리 만든 콘텐츠는 사용 가능하다.
  - **제작 시점 AI는 none이다.** AI로 단어·미션·질문 후보를 미리 생성하고 사람이 골라 덱으로 고정한 콘텐츠는 `none`으로 분류한다. 분류는 게임 진행 중 AI 호출 여부로만 정한다. (DEC-01)
- low: 미션 생성·보조 판정·요약 등 제한된 지점에서 사용한다.
- high: 진행 중 상황을 읽고 사건·미션·판정을 동적으로 바꾸는 것이 핵심이다.

AI 세부 정의는 이번 운영 규약이다. 필수 호출 단계와 실패 시 대체 동작도 적어 태그의 뜻을 확인할 수 있게 한다. high여도 AI가 계속 떠드는 설계는 허용 근거가 되지 않는다.

시간의 분 경계는 미정이다. 초기 아이디어의 1~3/4~8/10~20/20~40분과 로비 제안의 5~10/15~25/30분+는 서로 다른 제안이다. 이를 확정 기준으로 섞지 않는다. `estimated_duration_minutes`와 `duration_scope: game | pack`를 별도 기록한다. 설명·Reveal·전환을 포함한 실측 시간도 보존한다.

## 로비 편성 규약
사용자 조건: 관계, 원하는 길이, AI 개입 정도, 실제 참가 인원.
1. 출시 가능한 게임만 조회한다. 미검수 후보는 별도 테스트 로비에서만 사용한다.
2. 인원 범위와 추가 제약을 충족하는 게임을 남긴다. 권장 인원과 맞는 게임을 우선한다.
3. stranger 로비는 stranger/both, friends 로비는 friends/both를 매칭한다.
4. AI 설정은 우선 정확히 일치시킨다. low/high를 허용 상한으로 해석할지는 미정이다.
5. 길이와 예상 총시간을 확인한다. 게임팩이면 전환·설명·Reveal도 합산한다.
6. 조건에 맞는 풀이 없으면 조건 변경을 안내한다. AI 없음이나 인원 조건을 몰래 완화하지 않는다.
7. 인원이 변하면 다음 게임의 가능 여부를 재계산한다. 진행 중 이탈은 해당 게임의 명시된 규칙을 따른다.

`both`는 카탈로그 적합성 값이다. 혼합 관계 로비를 별도 UI 옵션으로 제공할지는 미정이다. 분위기 강도, deception/deduction/teamwork 등 보조 태그는 선택 사항이며 필수 분류를 대신하지 않는다.
