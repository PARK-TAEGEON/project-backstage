SD 관계·길이·인원은 원대화 카탈로그·인원 예시에 근거하고, `ai_intervention: none`은 DEC-01(사전 선정 단어 덱)에 따른다. EK 인원 3/[4,5,6]/8은 이번 문서의 검증 전 가설이다. 버전은 SD `0.1-context`, EK `0.0-context`이며 ASTRA/FABLE/사람 리뷰 기록 없음.

### SD — Secret Director
핵심: 각자 비밀 미션(예: 지정 단어를 대화에 자연스럽게 넣기)을 수행하고 서로 의심하다 마지막에 미션을 공개한다. 시작 미션·추리/투표·Reveal이 초기 구성이다.
콘텐츠: 런타임 AI 없이 **사전 선정 단어 덱**을 쓴다. 단어 후보는 AI로 대량 생성할 수 있으나 사용자가 직접 골라 덱에 넣는다. 선정 기준(가설): 대화에 넣을 수는 있지만 억지로 화제를 끌고 가야 하는 중간 난이도 — 너무 흔한 단어(“밥”, “오늘”)는 추리가 안 되고, 너무 튀는 단어(“양자역학”)는 즉시 들킨다.
보류 이유: 단어 덱 구성·난이도 기준, 성공 판정(사용 횟수·자연스러움), 점수/동률, 시간, 이탈 규칙, 3명 배정이 완성되지 않았다. 원대화의 AI 중간 사건은 이번 버전에서 제외했다.
다음: 비밀 단어 미션 방향은 [WORD — 단어 말하기](games/WORD.md)로 분리해 구체화했다(DEC-02). SD는 단어 외 비밀 미션을 쓰는 원안으로 보류하며, WORD 사람 테스트 결과를 본 뒤 재검토한다.

### EK — Everybody Knows Except You
핵심: 한 사람만 모르는 상황을 다른 참가자들이 채팅으로 연기하고 대상이 추리한 뒤 공개한다.
보류 이유: 정답 인정 기준, 역할 순환, 종료/실패, 3명에서 단서가 너무 뻔한지, 한 사람의 소외·불편함을 해결해야 한다.
다음: 채팅에서 관측 가능한 행동만으로 스펙화하고 종료·역할 순환을 정한다.
