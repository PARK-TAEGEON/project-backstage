# 구현 백로그 (스펙 리뷰의 비치명 지적)

`[x]` = 프로토타입에 구현하고 단위 테스트로 확인 (DEC-14, 2026-09-29).

DEC-13에 따라 ASTRA의 **치명이 아닌 지적**은 스펙 재리뷰 대신 여기 모아 두고, 구현·테스트 때 처리한다. 항목 옆 괄호는 리뷰 ID. 대부분은 이미 스펙이나 [09-ENGINE-RULES](../09-ENGINE-RULES.md)에 기본값으로 적혀 있고, 여기서는 **구현 때 테스트로 확인할 것**만 남긴다.

## 공통 엔진
- [x] 서버 접수 시각·접수 번호로 모든 판정 순서 고정, `시작 ≤ 접수 < 마감` 경계 테스트 (W-2, K-3, H-4)
- [x] 요청 ID 기반 1회 적용, 재전송 무시 테스트 (W-5)
- [ ] 종료 → 미완료 판정 확정 → 결과 잠금 → 공개 순서 테스트 (B-2)
- [ ] 이탈 확정 시간 실제 값 정하기 (기본 10초 구현됨), 재접속 상태 복원 테스트 (W-3, B-6) — 게임별 복원은 금지어·단어 말하기 구현 때
- [x] 3명 미만 시 새 라운드 시작 안 함, 전원 이탈 시 경기 중단 (W-3, B-5, K-4)
- [x] 비밀 정보 수신 권한을 서버에서 검사 (재접속 응답 포함), 그룹 변경 시 구독 해제 (B-6)
- [ ] AI 호출 3초 제한·재시도 0회·늦은 응답 폐기, 출력 검증 후 일괄 적용 (W-4, B-6) — 지금은 AI 없이 구현(DEC-18), AI를 붙일 때
- [ ] 문자열 NFC 정규화를 배정·채팅·추측·제출에 동일 적용 (W-5, K-1)

## 단어 말하기 (WORD)
- [x] 라운드 중 단어 득점 알림은 본인에게만, 다른 사람 점수는 Reveal 때 공개 (W-6) — 화면 갱신도 본인에게만
- [x] 잠금 검사 → 간격 검사 → 득점 순서, 간격은 실제 득점 기준 (W-2)
- [ ] 챌린지 간격 3초·같은 대상 10초가 적당한지 테스트에서 확인 (W-5)
- [x] 대체 단어 목록 고갈 시 시작 실패 안내 (W-4)
- [ ] **사람 테스트:** 90초×3라운드 길이, 10초 득점 간격 (DEC-20), 풀 3 단어 반응, 사회자 문장 빈도 (90초 라운드에서는 30초 침묵 조건상 라운드당 최대 1회)

## 금지어 (BAN)
- [x] 참가자 상태 전이(일반 → 챌린지 대기 → 입막힘/해제) 구현과 대기·입막힘 중 채팅 거부 (B-3)
- [x] 모든 그룹 종료 후 재편성, 먼저 끝난 그룹 대기 화면 (B-5)
- [x] 그룹별 배정 완료 후 공동 시작 시각 (B-6)
- [ ] 적발 공지가 1ms 늦게 나가 라운드 종료 직전이면 공개 뒤에 올 수 있음 (ASTRA 구현 메모 4)
- [ ] [제안] 공개 화면에 적발 직전 대화 몇 줄 (ASTRA 구현 메모 5)
- [ ] **사람 테스트:** 입 닫기 전략, 1번 풀 금지어의 가혹함, 7·8명 그룹 분할 체감

## 쿵쿵따 (KKT)
- [x] 표준국어대사전 내려받기, 스냅샷 버전 고정, 표제어 정규화 → 세 글자 목록 생성 (K-1) — DEC-19로 우리말샘 추가, `stdict-2026-06-05+opendict-2026-06-02`
- [ ] 사람 테스트: 우리말샘의 낯선 단어(지명·인명·방언)가 너무 쉽게 통과해 김빠지는지 관찰 (DEC-19)
- [x] 두음법칙 변환표 작성·버전 고정 (`dueum-1`, K-1)
- [x] 시작 글자 후보 = 미사용 답이 있는 글자만 (K-2)
- [x] 사전 로드 실패 시 경기 중단 처리 (K-3)
- [x] 이탈 순서로 탈락 순위 기록 (K-4)
- [x] 3명 경기에서 1명 이탈 시 남은 2명 — KKT 규칙 우선, 1:1 결승 진행 (DEC-16)
- [ ] **사람 테스트:** 차례 시간 10초→−0.25초/단어→최소 3초 체감(DEC-17), 소리 켬/끔 비교, 모바일 입력, 낯선 단어·한방단어 반응 (ASTRA 구현 메모)
- [ ] 재접속 유예 중에 차례가 오면 ‘시간 초과’로 기록됨 — ‘연결 끊김’과 구분할지 (ASTRA 구현 메모)

## 포브스 (WHO)

- [x] 첫 표 확정·후보 명단 고정·유효표 0 처리 (H-3, H-4)

## 눈치게임 (NUNCHI)
- [x] 단조 시계와 10ms 판정 창 구현, 창 닫힌 뒤 확정 (N-1, N-2)
- [ ] **실제 지연 관찰:** 0.001초 기준(DEC-15)에서 늦게 친 사람 판정이 억울하게 느껴지는지 사람 테스트로 기록
- [x] 무응답 10초는 유효 숫자 확정 기준으로만 갱신 (N-4)
- [x] 숫자 문법(ASCII 1~8)·부정출발·중복 제출 테스트 (N-5)
