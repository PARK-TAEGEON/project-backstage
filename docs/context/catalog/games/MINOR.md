## 한 줄 경험 / 차별점
전광판: **“적은 쪽이 이긴다!”** 밸런스 게임 질문(평생 여름 vs 평생 겨울)에 둘 중 하나를 고르는데, **진심은 상관없고 적은 쪽만 산다.** 채팅으로 “난 무조건 여름” 하고 겨울을 누르는 거짓말이 오간다. 발표 순간 “혼자 겨울 고른 민수, 나홀로 생존 +3” / “전원 여름… 단체 눈치 없음 −1”.
- 차별점: 눈치게임(NUNCHI)은 타이밍, 포브스(WHO)는 사람 지목이다. MINOR는 **동시 비밀 선택 + 소수 보상**이라 채팅 블러핑이 핵심이다. 질문은 핑계일 뿐 “진심으로 고르면 진다”는 불합리함이 웃음 포인트.

## 플레이 규칙
- setup: 덱에서 질문 7개를 중복 없이 무작위로 뽑는다. 점수 0에서 시작.
- private_info: 각자의 선택은 **마감 전까지 본인만** 안다. 서버는 다른 사람의 선택 내용을 보내지 않고 “선택 완료 N/M” 숫자만 보낸다. 마감 후 공개에서 전원 이름과 선택이 공개된다.
- round_flow: 3·2·1 → 질문과 A/B 버튼 표시, **선택 15초**(채팅 자유, 마감 전 변경 가능) → 마감 → 발표 6초(양쪽 명단·점수, 채팅 반응) → 다음 라운드. 7라운드.
- actions: A 또는 B 선택(변경 가능), 채팅.
- win_condition / scoring / ties:
  - 적은 쪽 전원 **+1**. 적은 쪽이 **딱 1명이면 +3** (“나홀로 생존”).
  - 양쪽 인원이 같으면 전원 0 (“무승부”).
  - 제출자 전원이 같은 쪽(만장일치)이면 제출자 전원 **−1** (“단체 눈치 없음”).
  - 무응답은 집계에서 빠지고 0점. 제출자가 2명 미만이면 그 라운드 무효(0점).
  - 최종: 합계 순, 동률은 공동 순위.
- end_condition / timeout / no_response: 7라운드 뒤 종료. 마감 때 선택이 없는 사람은 무응답.
- reveal: 라운드마다 “A 여름: 민수·지수·영희 / B 겨울: 철수” → 전광판 “🏝 나홀로 생존: 철수 +3”. 최종 결과에 “배신의 달인”(소수에 가장 많이 선 사람), “대세 추종러”(다수에 가장 많이 선 사람) 타이틀 [제안].
- replay_variation: 질문 덱 무작위, 사람들의 성향 읽기(“쟤는 늘 반대로 간다”)가 판마다 바뀐다.

## 구현 / 실패
- common_components: 중앙 카운트다운, 전광판 발표, 투표 입력(vote), 라운드 순위표([현재 순위], 08-UI-NOTES).
- ai_call_points / AI 사용 이유: 없음.
- judgment_criteria / deterministic_rules: 마감 시점 각자의 **마지막 유효 선택**을 센다. 적은 쪽·동수·만장일치 판정은 개수 비교만으로 결정.
- ai_failure_fallback: 해당 없음.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - 친구 담합(“둘이 B 가자”): 게임의 일부. 담합은 배신당할 수 있어서 오히려 웃음 포인트.
  - 매 라운드 무응답: 0점이라 손해. 만장일치 감점을 피하는 수단이 될 수 있음 → 테스트 관찰.
- social_risk / 소외 방지: 선택은 전략이지 진심이 아니라 놀림 부담이 적다. 질문은 포괄성 기준으로 검수.
- three_player_check: 3명이면 결과는 2:1(1명 나홀로 생존 +3) 또는 3:0(전원 −1)뿐이라 **동률이 생기지 않고 매 라운드 결판**이 난다. 모두가 “혼자이고 싶다”라서 가위바위보식 수 싸움이 되며, 채팅 블러핑이 유일한 단서다. 뻔해지는지(매번 3:0 반복 등) 3명 테스트 필요.
- 기타 인원 제약: 짝수 인원에서 동수(0점) 라운드가 나온다 — 의도된 허탈함.

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. MINOR 고유 사항:
- **투표 마감:** 선택 구간은 `시작 ≤ 접수 < 시작+15초`. 마감 후 접수는 무효. 선택 변경은 요청 ID별 1회 적용, 마지막 유효 선택이 확정값.
- **동률:** 라운드 동수 → 전원 0. 최종 합계 동률 → 공동 순위.
- **이탈:** 마감 전에 한 선택은 이탈 확정 여부와 관계없이 집계한다(이탈로 결과를 바꿀 수 없게). 이탈자 점수 유지. 다음 라운드 전에 인원을 다시 세고 3명 미만이면 누적 점수로 종료.
- **재접속:** 같은 라운드에 돌아오면 자기 선택과 점수를 복원.
- **3명:** 위 3명 점검 참고. 제출자 2명 미만 라운드는 무효.
- **비밀 정보 전달:** 마감 전 view에는 본인 선택과 제출자 수만 넣는다. 다른 사람의 선택·쪽별 인원은 마감 후 결과 잠금 뒤에만 전원에게 보낸다. 재접속 응답도 같은 권한.
