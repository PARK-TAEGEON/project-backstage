## 한 줄 경험 / 차별점
“받침 없는 말만!” — 모두가 “나 너 조아 해”처럼 부서진 말로 떠든다. 25초마다 규칙이 바뀌고, 바뀌기 0.1초 전에 친 말이 새 규칙에 **검거**당한다. 🚨
- BAN과 차이: 개인별 숨은 금지어가 아니라 **모두에게 공개된 같은 규칙**, 규칙이 계속 바뀐다, 말을 많이 할수록 득점.
- 폐기된 HR(숨은 규칙)과 차이: 규칙은 **전부 공개**되고 추리가 없다. 판정은 전부 코드 검사.

## 플레이 규칙
- setup: 규칙 목록(아래)에서 겹치지 않게 6개를 무작위로 뽑아 순서를 정한다.
- private_info: 없음. 다음 규칙은 누구에게도 미리 보내지 않는다 (바뀌는 순간 공개).
- round_flow:
  1. 중앙 3·2·1 → 첫 검문 규칙을 전광판처럼 크게 띄운다.
  2. 25초 동안 모든 채팅이 **검문 대상**이다. 25초가 지나면 다음 규칙으로 **즉시** 바뀐다 (쉬는 틈 없음, 번쩍 효과만).
  3. 6번째 규칙이 끝나면 게임 종료.
- actions: 채팅만. **한글 음절 4개 이상**인 메시지만 검문한다. 그보다 짧은 메시지(ㅋㅋ, ㄷㄷ, 헐, 이모지)는 자유 채팅 — 검문·득점 없음.
- 검문 결과:
  - **통과:** 현재 규칙을 지키고, 이 게임에서 통과된 적 없는 문장 → +1점. 단 득점은 사람당 **4초에 1번**(그 사이 통과 메시지는 0점).
  - **검거:** 규칙 위반, 또는 이미 통과된 문장 재탕(공백·문장부호 빼고 같으면 재탕) → −2점, 메시지는 🚨 도장과 함께 그대로 채팅에 올라가고, 보낸 사람은 **5초 입막힘**(그동안 메시지는 올라가지 않고 검문도 안 한다).
- win_condition / scoring / ties: 최종 점수 순. 점수는 음수 가능. 같으면 공동 순위.
- end_condition / timeout / no_response: 6 × 25초 고정 시간 뒤 종료. 아무도 말하지 않아도 끝난다 (전원 0점 공동 1위).
- reveal: 게임 끝에 순위 + **“오늘의 검거왕”**(검거 최다)과 그 사람의 가장 억울한 검거 메시지(규칙 전환 1초 안에 검거된 것 우선) 1개를 전광판에 띄운다.
- replay_variation: 20개 규칙 중 6개 조합·순서가 매번 다르다.

## 규칙 목록 (예시 20개 — 구현 때 확장)
모두 한글 음절(가~힣)·자모 분해·문자 검사로 판정한다. 각 규칙은 한글 4음절 이상으로 지킬 수 있음을 확인했다.
1. 받침 있는 글자 금지
2. 모든 글자에 받침
3. 초성 ‘ㅇ’ 글자 금지
4. 모음 ‘ㅏ’ 글자 금지 (중성이 ㅏ인 음절)
5. 정확히 7글자 (한글 음절 수)
6. 물음표(?)로 끝내기
7. 모든 어절이 같은 글자로 시작 (어절 2개 이상)
8. ‘요’·‘다’로 끝내기 금지 (마지막 한글 음절)
9. 숫자 하나 이상 넣기
10. 같은 글자 두 번 금지 (모든 음절이 서로 다름)
11. 첫 글자와 끝 글자가 같게
12. 어절 3개 이상, 모든 어절이 딱 두 글자
13. ‘ㄹ’이 들어간 글자 3개 이상 (초성 또는 받침)
14. 된소리(ㄲ·ㄸ·ㅃ·ㅆ·ㅉ) 글자 하나 이상
15. 띄어쓰기 금지 + 10글자 이상
16. 초성 ‘ㅎ’ 글자 2개 이상
17. 글자 수 홀수
18. 모든 어절이 한 글자 (어절 4개 이상)
19. 영어 알파벳 하나 이상 넣기
20. 느낌표 세 개(!!!)로 끝내기

- 어절 = 공백으로 나눈 조각 중 한글 음절이 1개 이상인 것. “글자”는 한글 음절만 센다 (영문·숫자·이모지·문장부호는 규칙 9·19·6·20 외에는 무시).

## 구현 / 실패
- common_components: 전광판, 중앙 카운트다운, 채팅 판정(`onChat` — 허용하되 도장 표시·입막힘은 BAN의 입막힘 부품 재사용), 정규화 함수, 한글 자모 분해 함수.
- ai_call_points / AI 사용 이유: 없음.
- judgment_criteria / deterministic_rules: 위 20개 규칙은 각각 순수 함수 `(정규화된 메시지) → 통과/위반`. 재탕 비교는 정규화 후 공백·문장부호를 뺀 문자열 일치.
- ai_failure_fallback: 해당 없음.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - 무의미 글자 도배(“가나다라”): 통과는 되지만 재탕 금지·4초 득점 간격으로 상한이 있다 (규칙당 최대 약 7점). 사람 테스트에서 도배가 재미를 죽이는지 관찰.
  - 짧은 메시지로 피하기: 4음절 미만은 득점도 없다 → 피할 이유가 없다.
  - 복사: 남의 통과 문장 복사는 재탕 검거.
- social_risk / 소외 방지: 타자가 느린 사람도 4초 득점 간격 덕에 격차가 제한된다 [가설]. 검거 메시지가 그대로 보이므로 욕설·불쾌 발언은 일반 채팅과 같은 정책(OPEN-12)을 따른다.
- three_player_check: 개인 점수 게임이라 역할·짝·다수결이 없다. 3명이면 채팅 양이 적어 “검거 구경” 재미가 줄 수 있으나 규칙 자체는 성립 (각자 규칙당 최대 약 7점, 검거 −2로 순위가 갈린다). 3명 테스트에서 채팅 밀도 확인.
- 기타 인원 제약: 8명이면 채팅이 빠르게 흐른다 → 검거 도장이 눈에 띄게 [제안].

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. GATE 고유 사항:
- **시간 경계:** 규칙 k의 구간은 `시작 + 25초×(k−1) ≤ 접수 < 시작 + 25초×k`. 메시지는 **서버 접수 시각의 규칙**으로 판정한다 — 이전 규칙을 보고 쳤어도 접수가 전환 뒤면 새 규칙으로 검거된다 (의도된 억울함). 마지막 구간 마감 이후 접수는 검문하지 않는 일반 채팅.
- **동시 입력:** 서로 영향을 주는 것은 재탕 판정뿐. 같은 문장이 거의 동시에 오면 **접수 번호가 빠른 쪽이 통과**, 늦은 쪽은 재탕 검거.
- **득점 간격:** 사람별 마지막 득점 접수 시각 + 4초 이전의 통과 메시지는 0점(검거 아님). 규칙이 바뀌어도 간격은 이어진다.
- **입막힘:** `검거 접수 ≤ 접수 < 검거 접수 + 5초`인 메시지는 방에 올리지 않고 본인에게 “🤐”만 보인다. 검거 판정과 입막힘은 한 번에 확정(09-2절).
- **이탈:** 점수 유지. 이탈자는 할 일(채팅)만 없어지고 다른 사람에게 영향 없다. 재접속하면 점수·입막힘 남은 시간·득점 간격을 복원.
- **3명 미만:** 라운드 구분이 없는 단일 게임이므로 남은 시간을 끝까지 진행하고 종료 (09-4절의 “진행 중 라운드는 마친다”). 전원 이탈 시 경기 중단.
- **판정 데이터:** 규칙 목록에 버전(`gate-rules-1`)을 붙인다.
