## 한 줄 경험 / 차별점
‘고’ → ‘고구’ → 떨리는 손으로 ‘고구마’… 💥 완성해 버렸다. 이어 붙일 글자는 있어야 하고, 단어가 되면 안 된다. 사전에 이상한 단어가 많아서 “그게 단어야?”로 무너지는 사람이 속출.
- KKT와 차이: 단어를 **완성하면 지는** 게임. 한 단어를 모두가 함께 한 글자씩 쌓는다. 끝말 잇기·세 글자 제한이 없다.
- 일반 끝말잇기(DEC-05 범위 밖)와 무관: 단어를 잇지 않는다.

## 플레이 규칙
- setup: 참가자 순서 무작위. 사전에서 뒤로 이어질 단어가 200개 이상인 **시작 글자**를 뽑아 탑 1층에 놓는다.
- private_info: 없음.
- round_flow:
  1. 중앙 3·2·1 → 시작 글자 공개, 첫 사람 차례.
  2. 차례인 사람이 전용 입력칸에 **한글 한 글자**를 내면 탑 위에 쌓인다.
  3. 판정:
     - 쌓은 결과가 **사전 단어(3글자 이상)와 정확히 같으면 → 폭사**, 라운드 종료.
     - 쌓은 결과로 **시작하는 단어가 사전에 하나도 없으면** → “❌ 그런 단어 없음” 거절, 같은 차례에 다시 (쌓이지 않음).
     - 그 밖(아직 단어가 아니지만 이어질 단어가 있음) → 통과, 다음 사람.
  4. 차례 시간 **7초** 안에 통과 못 하면 폭사.
  5. 다음 라운드는 폭사한 사람의 다음 사람부터, 새 시작 글자로.
- actions: 차례인 사람 — 한 글자 제출. 나머지 — 자유 채팅(“그거 단어야 ㅋㅋ”, 거짓 훈수).
- win_condition / scoring / ties: 6라운드 후 폭사 횟수가 적을수록 높은 순위. 같으면 공동 순위.
- end_condition / timeout / no_response: 사전을 **3~6글자 단어**로 제한하므로 탑이 5층이면 가능한 다음 글자는 전부 6글자 단어 완성 → 늦어도 6층에서 누군가 폭사(또는 시간 초과). 무응답은 7초 폭사. 6라운드 고정.
- reveal: 폭사 순간 완성된 단어와 **사전 뜻 한 줄**을 전광판에 (“고구마: 메꽃과의 여러해살이풀…”). 통과한 탑에는 “이렇게 이어질 수 있었다” 예시 단어 1개. 게임 끝 폭사 순위.
- replay_variation: 시작 글자 무작위, 사전이 커서 탑 모양이 매번 다르다.

## 콘텐츠 (예시 — 구현 때 사전에서 자동 계산)
사전: KKT와 같은 원본(표준국어대사전 + 우리말샘, DEC-19)에서 **단어 단위 표제어 중 한글 3~6음절**을 뽑아 접두어 트리로 만든다 (KKT 사전은 세 글자뿐이라 새로 빌드).
시작 글자 예시(이어질 단어 200개 이상 예상 — 구현 때 센다): 가, 고, 사, 바, 도, 마, 자, 하, 수, 미, 기, 나, 소, 비, 주, 대, 무, 해, 오, 부

## 구현 / 실패
- common_components: 전광판, 중앙 카운트다운, 전용 입력칸, 정규화 함수, KKT 사전 빌드 스크립트 확장(3~6음절), 뜻 표시.
- ai_call_points / AI 사용 이유: 없음.
- judgment_criteria / deterministic_rules: 제출 정규화(09-7절) 후 **한글 음절 정확히 1개**가 아니면 거절(재시도). 탑 글자열 s에 대해 `s ∈ 사전` → 폭사, `s로 시작하는 사전 단어 없음` → 거절, 그 외 통과. 두음법칙·동형어 구분 없음(글자열만 본다). 1~2층은 단어 완성 판정 대상이 아니다(3글자 이상만 단어).
- ai_failure_fallback: 해당 없음. 사전 로드 실패는 게임 시작 실패.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - 강제 폭사: 5층에서 차례가 오면 무조건 폭사 — 앞사람이 떠넘기는 전략이 핵심 재미(불합리함 의도).
  - 사전의 낯선 단어: 우리말샘 방언·옛말 때문에 “단어인 줄 몰랐다” 폭사가 잦을 것 → 웃음 포인트로 보되 짜증 여부 관찰. [가설] 인명·지명 범주는 사전에서 뺀다(실존 인물 이름이 완성 단어로 뜨지 않게).
  - 무의미한 글자 난사로 버티기: 막다른 글자는 거절되고 시간은 흐르므로 이득 없음. 같은 사람 제출은 0.3초 간격 이상.
- social_risk / 소외 방지: 차례가 빨리 돈다(라운드당 2~5차례 예상). 탈락이 없어 전원이 끝까지 참여.
- three_player_check: 3명이면 한 사람이 탑 1·4층 또는 2·5층을 맡게 되어 전략(떠넘기기)이 오히려 선명하다. 탈락이 없고 폭사 수만 세므로 6라운드 동안 전원 참여, 동률은 공동 순위. 성립.
- 기타 인원 제약: 7~8명이면 한 라운드에 차례가 안 오는 사람이 생긴다 → 다음 라운드 시작 위치가 이어지므로 게임 전체로는 고르게 돈다 [가설].

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. TOWER 고유 사항:
- **시간 경계:** `차례 시작 ≤ 접수 < 차례 시작 + 7초`인 제출만 판정. 마감과 같은 접수는 시간 초과 폭사. 차례 시작 = 직전 통과 판정 시각(라운드 첫 차례는 카운트다운 끝).
- **동시 입력:** 차례인 사람만 제출 가능. 한 차례에 통과 또는 폭사가 나면 그 뒤 같은 사람의 제출은 무효. 거절은 여러 번 가능.
- **이탈:** 이탈 확정자는 순서에서 빠지고 폭사 수는 유지(순위 계산에 포함). 차례인 사람이 유예 중이면 7초 뒤 폭사. 차례인 사람이 이탈 확정되면 **폭사 1회**를 기록하고 라운드 종료(이탈로 떠넘겨진 탑을 피할 수 없게). 재접속하면 폭사 수 복원, 순서에 다시 들어간다.
- **3명 미만:** 진행 중 라운드는 끝까지, 새 라운드 없음 → 누적 폭사로 순위 (09-4절).
- **판정 데이터:** 3~6음절 사전 스냅샷 버전(빌드 날짜)과 시작 글자 목록 버전을 기록.
