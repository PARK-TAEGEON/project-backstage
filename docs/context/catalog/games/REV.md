## 한 줄 경험 / 차별점
“간장공장공장장” → “장장공장공장간”. 뇌가 꼬여서 모두 “장공장…아니” 하고 있을 때, 가끔 나오는 **‘다시합창합시다’**는 거꾸로 해도 똑같다 — 눈치챈 사람이 1초 만에 1등.
- 기존 5개와 차이: 비밀·차례·생존이 없는 **변환 타자 퀴즈**. 모두 같은 문제를 동시에 푼다.

## 플레이 규칙
- setup: 문구 목록에서 8개를 뽑는다. 그중 2개는 **거꾸로 해도 같은 문구**(회문) 목록에서 [가설]. 어느 문제가 회문인지 알려 주지 않는다.
- private_info: 각자의 제출 내용은 라운드 끝까지 본인만 안다. 정답을 맞힌 사실(“✔ 민수”)만 모두에게 즉시 보인다.
- round_flow:
  1. 문구를 전광판에 크게 띄운다 (라운드 전환 때 짧게 3·2·1, 이후 문제는 1초 뒤 바로).
  2. 전용 입력칸에 **글자 순서를 뒤집어** 친다. 띄어쓰기·문장부호는 무시.
  3. 틀리면 “땡” + **2초 입력 잠김**, 다시 시도.
  4. 전원 정답이거나 20초가 지나면 문제 종료 → 정답 공개 → 다음 문제.
- actions: 전용 입력칸 제출, 자유 채팅. 단, 문제 진행 중 **정답이 들어간 채팅은 올리지 않는다**(스포 차단 — 보낸 사람에게만 “🤐”).
- win_condition / scoring / ties: 문제마다 정답 순서대로 1등 +3, 2등 +2, 이후 정답자 +1. 8문제 합계 순. 같으면 공동 순위.
- end_condition / timeout / no_response: 문제당 최대 20초, 8문제 고정 → 반드시 끝난다.
- reveal: 문제 끝마다 정답을 크게, 틀린 제출 중 **가장 많이 나온 오답**을 “땡 최다: ‘장공장장…’”으로 보여 준다. 게임 끝에 순위.
- replay_variation: 문구 조합·순서 무작위, 회문 문제 위치 무작위.

## 콘텐츠 (예시 20개 — 구현 때 확장)
한글만, 3~10음절. 속담·잰말놀이 등 저작권 없는 민속 문구와 직접 쓴 엉뚱한 문구. 인물·상표·성별·나이·직업·연애·음주·가족·외모 전제 없음.
- 일반(14): 간장공장공장장, 고양이가춤을춘다, 양말속에감자, 냉장고에들어간펭귄, 할일은내일의나에게, 짜장면먹고싶다, 바나나우유두개, 라면끓이는로봇, 우산없이춤추기, 가나다라마바사, 빨간풍선두개, 호랑이목도리, 감자튀김전쟁, 앞구르기뒷구르기
- 회문(6): 다시합창합시다, 자꾸만꿈만꾸자, 아좋다좋아, 나가다오나나오다가나, 토마토, 기러기
- 화면 표시는 자연스럽게 띄어 쓴 형태(예: “고양이가 춤을 춘다”), 판정은 공백을 뺀 글자열.

## 구현 / 실패
- common_components: 전광판, 중앙 카운트다운, 전용 입력칸, 정규화 함수, 채팅 판정(스포 차단), [현재 순위] 표.
- ai_call_points / AI 사용 이유: 없음.
- judgment_criteria / deterministic_rules: 정답 = 문구에서 한글 음절만 남긴 글자열의 역순. 제출도 정규화(09-7절) 후 한글 음절만 남겨 완전 일치. 스포 차단 = 채팅을 같은 방식으로 한글만 남겼을 때 정답 글자열을 **포함**하면 차단 (회문 문제는 원문 포함도 차단되므로 문구를 그대로 읽는 채팅도 막힌다 — 의도).
- ai_failure_fallback: 해당 없음.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - 복사·붙여넣기 후 역순 변환 도구: 막을 수 없다. 20초 안에 도구를 쓰는 수고 대비 이득이 작다고 본다 [가설].
  - 일부러 채팅에 정답 흘리기: 스포 차단으로 막는다. 일부만 흘리기(앞 3글자)는 허용 — 방해/도움 모두 놀이로 본다.
  - 난사: 2초 잠김이 억제한다.
- social_risk / 소외 방지: 타자 격차가 점수에 반영되지만 회문 문제는 속도보다 눈치라 역전 여지. 한 문제 최대 20초라 늦은 사람의 대기도 짧다.
- three_player_check: 3명이면 모두 정답 시 3·2·1점이 모두에게 돌아가 점수 차가 속도로만 난다 — 규칙 성립. 역할·다수결 없음. 동률은 공동 순위.
- 기타 인원 제약: 없음.

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. REV 고유 사항:
- **시간 경계:** 문제 구간 `공개 ≤ 접수 < 공개 + 20초`. 공개 전·마감 후 제출은 무효. 전원 정답으로 일찍 끝나면 그 시각이 마감.
- **동시 입력:** 정답 순위는 접수 번호 순 — 같은 ms라도 순서가 갈린다(공동 등수 없음).
- **잠김:** `오답 접수 ≤ 접수 < 오답 접수 + 2초`인 제출은 무효·무감점. 정답을 맞힌 사람의 추가 제출은 무효.
- **이탈:** 점수 유지. 남은 문제에서 “전원 정답” 판단은 **활성 참가자** 기준(이탈 확정자 제외). 재접속하면 점수·이번 문제 정답 여부·잠김 남은 시간 복원.
- **3명 미만:** 진행 중 문제는 끝까지, 이후 문제는 내지 않고 누적 점수로 종료 (09-4절; 8문제를 한 라운드로 보지 않고 **문제 하나를 라운드**로 본다).
- **판정 데이터:** 문구 목록 버전(`rev-phrases-1`).
