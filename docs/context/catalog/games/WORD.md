## 한 줄 경험
각자 몰래 받은 단어를 채팅에 최대한 많이 끼워 넣어 점수를 벌고, 남이 수상하면 단어를 맞혀 챌린지한다. 흔한 입버릇 단어는 숨기기 쉽고, “기체크로마토그래피”는 끼워 넣는 순간 모두가 눈치챈다 — 그 억지 변명이 웃음 포인트다.

## 경기 구조 [확정]
1. 방장이 **라운드 수**를 정한다. [기본값·가설: 1~5, 기본 3]
2. 라운드마다 새 단어를 받고 플레이한다.
3. 각 라운드가 끝나면 **라운드 점수를 집계**해 보여준다.
4. 모든 라운드가 끝나면 라운드 점수 합계로 **최종 순위**를 매긴다.

- 라운드 시간: [기본값·가설] 5분

## 단어 배정 [확정]
- AI가 라운드 시작 시 참가자에게 단어를 준다. 단어는 아래 세 풀의 정의를 따른다.
  1. 일상에서 자연스럽게 많이 쓰는 문장 구성어 (예: 아니, 근데, 이거)
  2. 사회 구성원으로서 많이 쓰는 단어 (예: 회사, 학교, 저녁)
  3. 되도 않는 길고 현학적인 전문용어 (예: 기체크로마토그래피)
- 1·2번 풀에서 무작위로 배정하고, **3번 풀 단어는 라운드당 0개 또는 1개만** 배정한다.
- **단어 형태 규칙** [확정]
  - **2음절 이상**만 배정한다. 1음절 단어는 다른 단어 속에서 우연히 잡히므로 배정하지 않는다.
  - **띄어쓰기 없는 한 단어**만 배정한다. 띄어쓰기가 있어야 자연스러운 표현(예: 한계효용체감의 법칙)은 풀에서 제외한다.
- [기본값·가설] 참가자 1인당 라운드마다 단어 1개. 같은 라운드에서 단어 중복 없음.
- AI 출력은 코드가 검증한다: 2음절 이상, 공백 없음, 같은 라운드 중복 없음, 금지어 목록 제외. 통과하지 못하면 대체 목록에서 뽑는다.
- AI 실패·지연 시 대체: 아래 **대체 단어 목록**에서 코드가 무작위로 뽑는다.

## 점수 [확정]
- **단어 사용:** 자기 단어가 들어간 채팅 메시지 1개당 +1점. **풀과 관계없이 모든 단어 동일** [확정: 풀 간 불공평함 자체를 재미 요소로 둔다]
- **인정 규칙:** 배정 단어의 **글자열이 메시지 안에 그대로 들어 있으면** 인정한다. 앞뒤에 무엇이 붙든 상관없고, 글자열이 조금이라도 다르면 인정하지 않는다. 판정은 이 규칙 하나로만 한다.
  - 인정 예시 (배정 단어 `회사`): `회사원`, `회사에서`, `우리회사`
  - 불인정 예시 (배정 단어 `근데`): `근디`(다른 글자), `ㄱㄷ`(초성), `근 데`(띄어쓰기), 오타
- 한 메시지에 여러 번 넣어도 1회로 센다.
- **도배 방지 간격:** 같은 참가자의 득점 메시지 사이에는 최소 간격이 있다. 간격 안에 보낸 메시지는 채팅으로는 올라가지만 점수는 없다. [기본값·가설: 15초]
- 집계는 **코드**가 한다. AI는 점수를 판정하지 않는다.

## 챌린지 [확정]
- 게임 중 누구나 다른 참가자를 클릭하고 그 사람의 단어를 추측해 적어 넣을 수 있다.
- **성공**(추측이 배정 단어와 일치): 챌린저 **+3점**, 대상은 이번 라운드에서 **더는 단어 점수를 얻지 못한다** (채팅은 계속 가능, 이미 얻은 점수는 유지).
- **실패:** 챌린저 **−3점**.
- 일치 판정: 앞뒤 공백을 제거한 뒤 배정 단어와 정확히 같을 때 성공. [기본값·가설]
- [기본값·가설] 공개 방식: 성공 시 대상의 단어를 모두에게 공개. 실패 시 “○○님 챌린지 실패”와 틀린 추측을 공개.
- [기본값·가설] 이미 잠긴 대상에게는 챌린지할 수 없다. 자기 자신에게도 할 수 없다.
- 점수는 음수가 될 수 있다.

## 사회자 (물꼬 트기) [확정]
- 채팅이 일정 시간 올라오지 않을 때만 사회자(AI)가 일상적인 말을 건넨다.
- [기본값·가설] 침묵 기준 30초, 최대 2분에 1회, 사람이 말하기 시작하면 추가 발화 없음.
- 사회자에게는 **채팅 내용을 보내지 않는다.** 사회자 발화는 점수 집계 대상이 아니다.
- [기본값·가설] **사회자(AI)에게 배정 단어를 보내지 않는다** (W-1). 생성 문장과 대체 문장 모두 서버가 배정 단어 포함 여부를 검사해, 들어 있으면 버린다. 통과 문장이 없으면 그 회차 발화 생략.
- AI 실패·지연 시 대체: 미리 쓴 기본 물꼬 문장 목록.

## 라운드 흐름
1. 라운드 시작: 개인 화면에 비밀 단어 표시.
2. 자유 채팅 (5분): 단어 사용 득점, 챌린지, 침묵 시 사회자 발화.
3. 라운드 종료: 모든 단어 공개(Reveal) → 사람별 사용 횟수·챌린지 결과·라운드 점수.
4. 다음 라운드로. 마지막 라운드 후 최종 순위.

Reveal에서 각자의 **가장 억지스러웠던 문장**(득점 메시지)을 함께 보여주면 “그래서 그랬구나”를 만들 수 있다. [제안]

## 동률 / 종료
- 라운드 종료: 타이머 만료. 참가자가 3명 미만이 되면 즉시 종료하고 그때까지 점수 집계. **이후 라운드는 시작하지 않고 누적 결과로 경기 종료** (W-3).
- 최종 동률: [기본값·가설] 챌린지 성공 수 → 그래도 같으면 공동 순위.

## 이탈 / 재접속
- [기본값·가설] 라운드 중 이탈: 점수 유지, **해당 라운드 끝까지 챌린지 대상 자격 유지** (W-3, 연결 해제로 챌린지 회피 방지). 같은 라운드에 재접속하면 단어·점수·잠금·마지막 득점 시각을 복원.
- 공통 정책은 OPEN-10을 따른다.

## AI 호출 지점
| 시점 | 입력 | 출력 | 실패 시 |
|---|---|---|---|
| 라운드 시작 | 풀 정의, 단어 형태 규칙, 인원, 3번 풀 배정 수(0/1), 제외 단어 | 단어 목록 | 대체 단어 목록에서 코드가 뽑음 |
| 침묵 감지 | 사회자 지침만 (배정 단어 전달 금지) | 한 문장 | 기본 물꼬 문장 (둘 다 서버 검사) |

- 채팅 로그는 AI에 보내지 않는다. 점수 집계·챌린지 판정은 코드.
- 예상 사용량: 한 판(3라운드)에 호출 약 3~12회, 수천 토큰 이하. 테스트는 무료 티어로 충분하다고 판단 [가설].

## 3명 점검
- 서로 2명만 의심하면 되므로 챌린지 난도가 낮아진다. 쉬운 풀(1번) 단어가 오히려 유리할 수 있다 → 3명 테스트 필수.

## 알려진 위험 / 악용
- **짧은 단어 속 우연 포함:** 2음절이어도 더 긴 단어 안에서 잡힐 수 있다 (예: `카페` → 카페인). 인정 규칙상 득점으로 본다.
- **풀 간 난이도 차이:** 1번 풀 단어는 거의 공짜 점수, 3번 풀은 쓰는 순간 발각. 의도된 불공평함이다 [확정]. 사람 테스트에서는 3번 풀을 받은 사람이 재미있어하는지, 포기하는지를 관찰한다.
- **무작정 챌린지:** −3점이 억제하지만, 막판 역전을 위한 난사 가능성은 테스트 필요.
- **의미 없는 짧은 메시지 반복:** 도배 간격으로 제한. “회사.” 같은 반복은 여전히 가능 — 발각 위험이 억제 장치.
- **소외:** 챌린지에 잠긴 참가자는 남은 시간 동안 할 일이 챌린지뿐 → 챌린지 득점은 가능하므로 참여는 유지됨. 체감은 테스트 필요.

## 구현 메모 (프로토타입, DEC-18) [기본값·가설]
- **AI 없음:** 아래 “AI 호출 지점”은 쓰지 않고 “실패 시” 경로만 쓴다. 단어는 `wordcore/pools.ts`의 풀 1 100개·풀 2 130개·풀 3 80개(`pools-1`), 사회자는 미리 쓴 문장 40개. 코드가 형태 규칙을 다시 검사한다.
- 풀 3 배정은 라운드마다 반반 확률로 0개 또는 1개. 같은 경기에서 이미 나온 단어는 되도록 다시 주지 않는다.
- 라운드 수 3·라운드 5분은 고정 (방에서 바꿀 수 없음, DEC-15 — “방장이 라운드 수를 정한다”는 적용하지 않음).
- 흐름: 소개 4초(내 단어 크게) → 진행 5분 → 공개 10초 (모든 단어·사용 횟수·챌린지 점수·가장 긴 득점 문장).
- 득점하면 본인 화면에만 “+1 🤫”, 다음 득점까지 남은 시간 표시. 화면 갱신도 본인에게만 보낸다.
- 챌린지는 참가자 카드의 🎯 버튼 → 추측 입력. 잠긴 사람도 챌린지는 할 수 있다.

## 판정·처리 규약 (ASTRA 1차 반영) [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. WORD 고유 사항:
- **처리 순서 (W-2):** 메시지 접수 시 ① 라운드 마감 전인가 → ② 보낸 사람이 잠겨 있지 않은가 → ③ 마지막 실제 득점 후 15초 이상 지났는가 → ④ 배정 단어 포함 → +1. 간격은 **실제로 득점한 메시지** 기준이다.
- **챌린지 확정:** 성공 판정·챌린저 +3·대상 잠금을 한 번에 확정한다. 같은 대상에 대한 동시 챌린지는 접수 번호가 빠른 쪽만 처리하고, 이미 잠긴 대상에 대한 뒤 요청은 무효·감점 없음.
- **챌린지 제한 (W-5):** 참가자별 챌린지 간격 3초, 같은 대상 재도전 간격 10초.
- **단어 배정 (W-4):** AI 호출 3초·재시도 0회. 정확히 N개, 중복 없음, 풀 3 지정 수(0 또는 1) 충족, 2음절 이상·공백 없음을 모두 검증한 뒤 한꺼번에 배정. 대체 목록도 같은 검증. 부족하면 시작 실패 안내.
- **비밀 정보:** 자기 단어는 본인에게만 보낸다. **라운드 중 단어 득점은 본인에게만 알린다.** 다른 사람의 단어 점수는 라운드 종료(Reveal) 때 공개한다 (W-6: 실시간 공개 시 어떤 메시지가 득점했는지로 비밀 단어가 드러남). 챌린지 결과(성공·실패, ±3)는 지금처럼 즉시 모두에게 공개한다.
