## 한 줄 경험 / 차별점
차례대로 1, 2, 짝, 4… 를 채팅에 친다. **짝이 나올 때마다 순서가 거꾸로 돈다.** 채팅창에는 구경꾼들이 친 가짜 숫자가 쏟아지고, 33에서 “짝” 한 번만 친 사람이 탈락한다.
- NUNCHI와 차이: 동시 경쟁·겹침이 없고 **정해진 차례**가 있다. 틀리면 탈락하는 셈하기·반사 게임.
- KKT와 차이: 단어·사전이 없고, 3·6·9 셈 + 방향 반전이 핵심. 틀린 입력은 재시도 없이 즉시 탈락.

## 플레이 규칙
- setup: 참가자 순서를 무작위로 정해 원형으로 보여 준다. 방향은 시계 방향으로 시작.
- private_info: 없음.
- round_flow:
  1. 중앙 3·2·1 → 첫 차례 강조, 숫자 1부터.
  2. 차례인 사람이 채팅에 다음 수를 친다. 수에 3·6·9가 **k개** 들어 있으면 숫자 대신 **‘짝’을 정확히 k번**(예: 3 → 짝, 33·36 → 짝짝, 13 → 짝, 30 → 짝).
  3. 맞으면 다음 사람 차례. **‘짝’으로 넘긴 경우 방향이 뒤집힌다** (A→B→C 중 B가 짝 → 다음은 A).
  4. 틀린 수·틀린 짝 개수·차례 시간 초과 → **탈락**, 라운드 종료.
  5. 다음 라운드는 탈락자 다음 사람(원래 방향 기준)부터 1로 다시 시작. 방향은 시계 방향으로 초기화.
- actions: 차례인 사람 — 수 또는 짝. 나머지(탈락자 포함) — 자유 채팅. **차례 아닌 사람이 친 숫자·짝은 그냥 채팅**이다 → 가짜 숫자로 방해해도 된다.
- 차례 시간: 4초에서 시작, 경기에서 수가 하나 이어질 때마다 0.1초씩 줄고 최소 2초 (라운드가 바뀌어도 이어서 줄어든다 — KKT 방식).
- win_condition / scoring / ties: 마지막 생존자 1위, 탈락 역순으로 순위. 같은 순간 둘 이상 탈락하는 경우는 없음(차례는 한 명). 상한 시 공동 순위(아래).
- end_condition / timeout / no_response: 생존자 1명이면 종료. 무응답은 차례 시간 초과로 탈락하므로 멈추지 않는다. **안전 상한: 게임 6분**이 지나면 진행 중 라운드를 즉시 끝내고 남은 생존자는 공동 1위.
- reveal: 탈락 순간 전광판에 “💥 ○○ · 33에서 ‘짝’” (친 것 / 정답). 게임 끝에 순위와 **최고 도달 수**.
- replay_variation: 순서 무작위, 방향 반전으로 차례 흐름이 매번 다르다.

- ai_call_points / AI 사용 이유: 없음.
- judgment_criteria / deterministic_rules:
  - 차례인 사람의 메시지를 앞뒤 공백 제거 후 **수 토큰**인지 본다: ① ASCII 숫자만(`[0-9]+`) 또는 ② ‘짝’과 공백만(‘짝’ 1개 이상). 그 밖의 메시지(“아 잠깐”, `짝!`, 전각 숫자)는 판정하지 않는 일반 채팅.
  - 정답: 현재 수 n의 3·6·9 자릿수 개수 k. k=0이면 n을 앞자리 0 없이 그대로, k≥1이면 공백을 뺀 ‘짝’ 개수가 정확히 k.
  - 수 토큰이 정답이 아니면 탈락.
- ai_failure_fallback: 해당 없음.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - 가짜 숫자 방해는 의도된 재미. 판정은 차례인 사람의 메시지만.
  - 차례를 예상하고 미리 친 수: 차례 시작 전 접수면 그냥 채팅 → 다시 쳐야 한다 (억울 포인트).
- social_risk / 소외 방지: 첫 탈락자는 관전 — 방해 채팅이 참여 수단. 차례 시간이 계속 줄어 대기는 짧을 것으로 예상 [가설].
- three_player_check: 3명이면 2라운드. 방향 반전은 3명에서도 의미가 있다 (A→B→C에서 B가 짝이면 A로). 1:1 결승은 두 사람이 번갈아 치므로 반전의 영향은 없지만 셈·시간 압박은 유지. 1:1 진행은 09-4절 예외(아래).

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. CLAP 고유 사항:
- **시간 경계:** 차례 시작 = 직전 정답 접수 시각(라운드 첫 차례는 카운트다운 끝). `차례 시작 ≤ 접수 < 차례 시작 + 차례 시간`인 수 토큰만 판정. 마감과 같은 접수는 시간 초과.
- **한 번만:** 한 차례에 판정하는 수 토큰은 **첫 번째 하나**뿐. 정답이면 차례가 즉시 넘어가 같은 사람의 두 번째 토큰은 일반 채팅이 된다.
- **동시 입력:** 차례는 한 명이라 경쟁이 없다. 다른 사람의 토큰은 접수 순서와 무관하게 판정하지 않는다.
- **카운트다운 중 입력:** 판정하지 않는 채팅 (부정출발 없음).
- **1:1 결승:** 09-4절(3명 미만 새 라운드 없음)의 **예외 요청** — KKT(DEC-16)처럼 1명 남을 때까지 진행한다. 사용자 결정 전 [미정]; 예외를 받지 않으면 3명→2명이 되는 순간 누적 결과(탈락 역순, 생존자 공동 1위)로 끝낸다.
- **이탈:** 이탈 확정 순서대로 탈락으로 기록(그 시점 순위). 차례인 사람이 유예 중이면 차례 시간이 지나면 시간 초과 탈락. 차례가 아닌 사람의 이탈은 순서에서 빼고 라운드 계속. 재접속해도 탈락은 취소되지 않는다. 전원 이탈 시 경기 중단.
- **안전 상한:** 6분 도달 시 진행 중인 차례의 판정은 버리고 생존자 공동 1위.
