## 한 줄 경험 / 차별점
전광판: **“폭탄 3개, 우리 중에 해체범이 있다!”** 폭탄마다 무작위 출동조가 몰래 ✂️해체 / 💣폭파 카드를 낸다(해체반은 해체만 가능). 결과는 **폭파 카드 수만** 공개 — “💥 폭파 1장!” 출동조 명단과 결과를 맞춰 보며 서로 몰아세우고, 마지막에 한 번 지목한다. 발표: **“해체범은… 민수였습니다!”** + 누가 몇 번 폭탄에서 폭파를 눌렀는지까지.
- 차별점: 마피아처럼 밤·탈락·사회자가 없다(아무도 중간에 빠지지 않음). 비밀 미션 제출형 게임 계열이지만 **리더의 팀 구성 협상을 없애고 서버가 출동조를 무작위 배정**, 미션 3개 고정·최종 지목 1회로 3.5분에 끝낸다. 추리 단서가 “출동조 명단 × 폭파 장수”라 코드로 완전히 판정된다.

## 플레이 규칙
- setup: 역할 무작위 배정. 해체범이 2명이면 서로를 안다. 출동조 인원: 3명 2 · 4명 2 · 5명 3 · 6명 3 · 7명 4 · 8명 4. 폭탄 3개의 출동조를 시작 때 서버가 정하되, **모든 참가자가 최소 1번 출동**하고 **같은 출동조가 반복되지 않게** 한다(3명이면 가능한 2인조 3개가 한 번씩).
- private_info:
  - 역할: 본인에게만. 해체범에게는 동료 해체범 명단도.
  - 카드 제출: 누가 무엇을 냈는지는 **최종 공개 전까지 아무에게도** 보내지 않는다. 폭탄마다 공개되는 것은 폭파 장수뿐.
  - 출동조 명단은 공개 정보(폭탄마다 출동 직전에 발표).
- round_flow:
  1. 역할 확인 5초.
  2. 폭탄 1~3 각각: 출동조 발표 3초 → **카드 제출 10초**(출동조만, 시간은 고정 — 전원 제출해도 조기 종료 안 함) → 결과 4초(“✅ 해체 성공” / “💥 폭파 N장”) → **토론 30초**(전원 채팅).
  3. 최종 토론 40초 → **지목 투표 12초**(전원, 자기 제외 1명) → 공개 10초.
- actions: 출동조 — 카드 제출(해체반은 ✂️해체만, 해체범은 ✂️/💣). 전원 — 채팅, 최종 지목.
- win_condition / scoring / ties:
  - **해체범 팀 승리:** 폭파된 폭탄이 1개 이상 **그리고** 최다 득표자가 해체범이 아님.
  - **해체반 승리:** 그 외 전부(폭탄 3개 모두 해체, 또는 최다 득표자가 해체범).
  - 최다 득표 동률: 지목 실패로 본다(해체범에게 유리).
  - 순위: 승리 팀 전원 공동 1위, 패배 팀 전원 공동 다음 순위.
- end_condition / timeout / no_response: 카드 미제출은 ✂️해체로 센다. 지목 무응답은 기권. 공개로 종료.
- reveal: 전광판 “해체범은… ○○!” → 폭탄별 누가 💣를 냈는지 → 지목 표(누가 누구를 찍었는지 공개 — 이 게임에서는 고발이 곧 플레이) → 승리 팀. “억울한 누명”(해체반인데 최다 득표) 타이틀 [제안].
- replay_variation: 역할·출동조 조합이 매번 무작위.

## 구현 / 실패
- common_components: 전광판, 역할 비공개 표시, 카드 버튼(action), 투표(vote), 중앙 카운트다운.
- ai_call_points / AI 사용 이유: 없음.
- judgment_criteria / deterministic_rules: 폭파 장수 = 💣 제출 수. 해체반의 💣 요청은 서버가 거부(해체로 처리하지 않고 무시, 재제출 가능). 승패는 위 두 조건.
- ai_failure_fallback: 해당 없음.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - 해체범이 한 번도 폭파하지 않으면 자동 패배 → 반드시 흔적을 남기게 만드는 장치.
  - 채팅으로 역할 자백·거짓 자백: 심리전의 일부.
  - 화면 공유로 역할 증명: 온라인 게임 밖 행동, 막지 않음.
- social_risk / 소외 방지: 탈락 없음, 출동은 모두 최소 1회, 토론은 전원. 해체범은 소수라 몰림이 생기지만 한 판 3.5분으로 짧다. 최종 지목 공개가 싫다는 반응이 나오면 표 수만 공개로 바꿀 수 있음 [미정].
- three_player_check: 3명(해체범 1)은 2인조 3개가 한 번씩이라 해체범은 두 번 출동한다. 폭파하면 같이 출동한 해체반 1명은 범인을 **확신**하고, 밖에 있던 1명은 둘 중 누구인지 모른다 → 최종 지목은 **확신한 사람 vs 해체범의 설득 대결을 나머지 1명이 판정**하는 구조가 된다. 두 번 폭파하면 교집합으로 들통나므로 해체범은 한 번만, 언제 폭파할지 고민한다. 투표는 3표이고 자기 지목 불가라 동률이 나지 않는다(심판 1명이 가른다). 뻔해지는지 3명 테스트 필요.
- 기타 인원 제약: 6~8명 해체범 2명은 폭파 2장이 나오면 강한 단서가 된다 — 밸런스는 테스트로.

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. DEFUSE 고유 사항:
- **마감:** 카드 `시작 ≤ 접수 < 시작+10초`, 지목 `시작 ≤ 접수 < 시작+12초`. 마지막 유효 제출이 확정값. 출동조가 아닌 사람의 카드, 자기 지목은 무효.
- **동률:** 최다 득표 동률 → 지목 실패. 유효표 0 → 지목 실패.
- **이탈:** 역할과 투표 대상 자격은 이탈해도 유지(09 4절). 출동조에서 이탈 확정된 사람은 해체로 센다. **해체범 전원이 이탈 확정되면** 즉시 공개하고 해체반 승리. 참가 중 인원이 3명 미만이 되면 진행 중인 폭탄 단계만 마치고 지목 없이 공개, **경기 중단(전원 공동 순위)**으로 기록.
- **재접속:** 역할·동료 명단·이미 낸 카드·지목을 본인에게 복원.
- **3명:** 위 점검 참고.
- **비밀 정보 전달:** 역할과 동료 명단은 본인(해체범끼리)에게만, 재접속 응답도 같다. 해체반 view에는 💣 버튼 존재 여부조차 넣지 않는다(해체범 view에만). 제출 여부·제출 순서·제출 시각은 누구에게도 보내지 않고, 폭탄 결과는 마감 후 결과 잠금 뒤 폭파 장수만 보낸다. 누가 💣를 냈는지는 최종 공개 전까지 서버 밖으로 나가지 않는다.
