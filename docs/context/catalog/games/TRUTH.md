## 한 줄 경험 / 차별점
전광판: **“진실일까 뻥일까?”** 발표자는 질문(“지금 폰 배터리 몇 %?”)과 함께 **시스템이 몰래 정해 준 지시(🟢진실 / 🔴뻥)**를 받는다. 답을 올리면 나머지가 20초 동안 채팅으로 심문하고 진실/뻥에 투표한다. 발표: **“🔴 뻥이었습니다! 속은 사람: 지수·철수”**.
- 차별점: 흔한 “두 개의 진실과 하나의 거짓”은 본인이 무엇을 속일지 고르고 개인사를 꺼내야 한다. TRUTH는 **동전이 거짓말을 강제**하고 질문이 “지금 상태”라 사적인 폭로가 없다. 라이어 게임처럼 단어를 설명하는 구조도 아니다. “배터리 3%라고? 뻥이지” → “진실입니다” 순간이 웃음 포인트.

## 플레이 규칙
- setup: 발표 순서를 무작위로 정한다. **라운드 수 = 인원 5명 이상이면 인원 수, 4명 이하면 인원 × 2**(3명 6라운드, 4명 8라운드). 질문은 덱에서 중복 없이 뽑는다.
- private_info: 라운드마다 서버가 지시(진실/뻥, 각 50%)를 뽑아 **발표자 view에만** 넣는다. 다른 참가자의 투표 내용과 현재 표 수는 마감 전까지 아무에게도 보내지 않는다. 지시는 발표 단계에서 전원에게 공개.
- round_flow:
  1. 질문 공개(전원) + 지시(발표자만) — 3초
  2. **답변 15초:** 발표자가 전용 입력칸(text, 30자 이내)에 답 제출 → 큰 카드로 전원에게 표시. 제출하면 즉시 다음 단계.
  3. **심문·투표 25초:** 전원 채팅 자유. 발표자 외 전원이 🟢진실 / 🔴뻥에 투표(마감 전 변경 가능).
  4. **발표 6초:** 지시 공개, 속은 사람·맞힌 사람 명단, 점수.
- actions: 발표자 — 답 제출, 채팅 변론. 나머지 — 투표, 채팅 심문.
- win_condition / scoring / ties:
  - 투표자: 맞히면 **+1**.
  - 발표자: 틀린 투표자 1명당 **+1**. 투표한 사람 전원을 속이면 추가 **+2** (“사기꾼 인증”).
  - 무투표는 0점이며 발표자 점수에도 들어가지 않는다.
  - 최종: 합계 순, 동률은 공동 순위.
- end_condition / timeout / no_response: 발표자가 15초 안에 답을 안 내면 **“묵비권” −1**, 그 라운드는 투표 없이 종료. 모든 라운드가 끝나면 종료.
- reveal: 라운드마다 전광판 “🔴 뻥이었습니다!” / “🟢 진짜였습니다!” + 속은 사람 명단. 최종 결과에 “사기꾼 1위”(발표 득점 최고), “거짓말 탐지기”(투표 적중 최다) 타이틀 [제안].
- replay_variation: 질문 덱과 지시 동전이 매번 달라진다.

## 질문 덱 (예시 20개, 구현 때 확장)
기준: “지금·최근 상태”만 묻는다. 성별·나이·직업·연애·음주·가족·외모·건강을 전제하거나 캐지 않는다.
1. 지금 폰 배터리 몇 %?
2. 오늘 일어난 시각은?
3. 어젯밤 몇 시에 잠들었어?
4. 지금 손 닿는 곳에 있는 물건 하나는?
5. 폰 사진첩 제일 최근 사진은 뭐 찍은 거?
6. 오늘 마신 물 몇 잔?
7. 알람 몇 개 맞춰 둬?
8. 오늘 처음 먹은 음식은?
9. 폰 홈 화면 앱 개수는?
10. 지금 열려 있는 탭(창) 개수는?
11. 마지막으로 넘어진 게 언제?
12. 지금 주변에서 들리는 소리 하나는?
13. 이번 달에 산 것 중 제일 쓸데없는 것은?
14. 가장 최근에 흥얼거린 노래 장르는?
15. 지금 제일 먹고 싶은 음식은?
16. 어제 대충 몇 걸음 걸었어?
17. 가장 최근에 받은 알림은 무슨 종류?
18. 지금 주변(책상·바닥) 위 물건 개수는?
19. 오늘 거울 본 횟수는? → 외모 연상 가능, 구현 때 검수 후 제외 여부 결정 [미정]
20. 지금 앉은(누운) 자세는?

## 구현 / 실패
- common_components: 전광판 발표, 전용 입력칸(text), 투표(vote), [현재 순위].
- ai_call_points / AI 사용 이유: 없음.
- judgment_criteria / deterministic_rules: 정답은 **서버가 뽑은 지시**다. 발표자가 실제로 진실을 말했는지는 판정하지 않는다(확인 불가). 투표 = 지시와 일치 여부로 채점.
- ai_failure_fallback: 해당 없음.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - **지시 무시:** 🟢인데 거짓을 말하거나 그 반대. 판정은 지시 기준이라 발표자 입장에서는 “상대가 지시를 못 맞히게 하는” 같은 게임이 된다 — 규칙 붕괴 없음. 분위기만 관찰.
  - **자백:** 발표자가 채팅에 “나 뻥이야” — 자기 점수만 잃는다.
  - 답변 칸에 불쾌한 내용 — 일반 채팅과 같은 위험(OPEN-12).
- social_risk / 소외 방지: 발표자가 돌아가며 모두에게 주인공 순간이 있다. 질문은 사적 폭로가 없는 현재 상태형.
- three_player_check: 3명이면 발표자 1 vs 투표자 2. 두 바퀴(6라운드)로 각자 두 번 발표. 표가 2개뿐이라 “전원 속이기(+2+2)”가 쉬워 발표자 쪽이 유리할 수 있음 → 3명 테스트에서 점수 쏠림 확인(점수는 재미용이라 치명 아님). 투표자가 2명이어도 심문 채팅은 성립.
- 기타 인원 제약: 8명은 8라운드로 가장 길다(약 6.4분).

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. TRUTH 고유 사항:
- **마감:** 답변 `시작 ≤ 접수 < 시작+15초`. 투표 `심문 시작 ≤ 접수 < 심문 시작+25초`, 마지막 유효 투표가 확정값. 발표자 투표는 서버가 거부.
- **동률:** 라운드에는 다수결이 없어 동률 없음(개인별 적중 채점). 최종 합계 동률은 공동 순위.
- **이탈:** 발표자가 답 제출 전에 이탈 확정되면 그 라운드는 무효(점수 없음)로 넘어간다. 답 제출 뒤 이탈하면 라운드는 그대로 진행하고 점수 유지. 이미 이탈 확정된 사람의 발표 차례는 건너뛴다(라운드 수 감소). 다음 라운드 전 3명 미만이면 누적 점수로 종료.
- **재접속:** 같은 라운드에 돌아온 발표자에게 지시를 다시 보낸다(본인에게만). 투표자는 자기 투표 복원.
- **3명:** 위 점검 참고.
- **비밀 정보 전달:** 지시는 발표자 view에만, 재접속 응답도 발표자에게만. 표 수·투표자 명단은 결과 잠금 뒤에만 전원에게. 발표자 화면의 지시 색(🟢/🔴)이 다른 사람 view에 섞이지 않게 서버에서 분리한다.
