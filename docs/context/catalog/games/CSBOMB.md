## 한 줄 경험 / 차별점
언제 터질지 아무도 모르는 폭탄을 들고 **초성 세 글자(ㄱㅅㄱ)**에 맞는 단어를 쳐야 넘길 수 있다. 겨우 넘겼더니 3초 만에 다시 돌아오고, 들고 있는 순간 “펑”.
- KKT와 차이: 순서·끝말 잇기가 없다. 모두 같은 초성을 쓰고, 탈락은 시간 초과가 아니라 **숨은 도화선**(운)이 정한다. 차례 시간이 없다 — 대신 “들고 있는 시간 = 위험”.
- NUNCHI와 차이: 동시 입력 경쟁이 아니라 한 명이 쥐고 있는 폭탄 돌리기.

## 플레이 규칙
- setup: 라운드마다 서버가 **초성 3개**를 뽑는다 (사전에서 답이 40개 이상인 조합만). 첫 폭탄 소지자는 무작위.
- private_info: **도화선 길이(15~35초 균등 무작위)는 서버만 안다.** 누구에게도 보내지 않는다 (view·재접속 상태·알림 포함). 폭발 뒤 공개.
- round_flow:
  1. 중앙 3·2·1 → 초성 공개(전광판 크게), 폭탄 소지자 표시, 도화선 시작.
  2. 소지자가 전용 입력칸에 단어 제출 → 맞으면 폭탄이 **소지자를 뺀 참가자 중 무작위 1명**에게 넘어간다.
  3. 틀리면 “❌ 없는 단어!”로 알리고 계속 들고 있다 (재시도 무제한, 도화선은 흐른다).
  4. 도화선이 끝나는 순간의 소지자가 **폭사**. 라운드 종료.
- actions: 소지자 — 단어 제출. 나머지 — 자유 채팅(방해·응원·오답 유도). 입력칸은 모두에게 보이고 제출 버튼은 소지자에게만 켜진다.
- win_condition / scoring / ties: 폭사 횟수가 적을수록 높은 순위. 같으면 **통과시킨 단어 수**가 많은 쪽이 위. 그래도 같으면 공동 순위.
- end_condition / timeout / no_response: 5라운드 후 종료. 소지자가 아무것도 안 해도 도화선이 끝나면 라운드가 끝나므로 무응답으로 멈추지 않는다.
- reveal: 라운드 끝에 “💥 ○○ 폭사 · 23.4초” + 이번 라운드 단어 줄(누가 무엇으로 넘겼는지) + **아무도 안 쓴 정답 3개**(“이런 것도 있었다”). 게임 끝에 폭사 순위.
- replay_variation: 초성 조합은 사전에서 자동 계산하므로 수천 개. 도화선·전달 대상이 매번 무작위.

- judgment_criteria / deterministic_rules: 정규화(09-7절) 후 **한글 음절 정확히 3개**, 각 음절의 초성이 문제와 순서대로 정확히 일치, 사전에 있음, 이번 게임에서 아직 안 쓴 단어. 두음법칙은 적용하지 않는다 (초성 일치만 본다).
- ai_failure_fallback: 해당 없음. 사전을 못 불러오면 게임 시작 실패로 알린다.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - 핑퐁 몰아가기 불가: 전달 대상은 시스템 무작위라 특정인에게 몰 수 없다.
  - 단어 외워 오기: 초성이 수천 조합이라 효과가 작다.
  - 초성 답 고갈: 남은 답이 0이 되면 **폭탄·도화선은 그대로 두고 초성만 새로 뽑는다**.
- social_risk / 소외 방지: 폭탄이 안 오는 사람은 할 일이 채팅뿐 → 전달이 잦아(단어 하나 3~5초 예상) 대기가 짧다 [가설]. 같은 사람에게 연속으로 오는 억울함은 의도된 웃음 요소, 테스트에서 짜증 여부 관찰.
- 사전 콘텐츠 위험: 우리말샘의 인명·지명 표제어가 “정답 3개” 공개에 뜰 수 있다 → [가설] 공개용 예시에서는 인명·지명 범주를 뺀다 (판정은 KKT와 동일 사전).
- three_player_check: 3명이면 전달 대상이 항상 나머지 2명 중 하나 → 폭탄이 자주 돌아와 긴장은 오히려 크다. 폭사는 라운드당 1명이라 5라운드면 누구나 한두 번 터질 수 있고 순위도 성립(동률은 통과 단어 수로 가름). 정보 비대칭·팀 구성이 없어 인원 제약 없음.
- 기타 인원 제약: 없음.

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. CSBOMB 고유 사항:
- **시간 경계:** 폭발 시각 = 라운드 시작 + 도화선. 제출은 `소지 시작 ≤ 접수 < 폭발 시각`일 때만 판정한다. 폭발 시각과 같은 접수는 무효(폭사 확정). 폭발 직전 접수된 정답은 판정이 늦게 끝나도 유효 → 폭탄은 넘어간 뒤 받은 사람이 즉시 폭사한다 (억울함 = 웃음 포인트).
- **소지 시작:** 폭탄을 받은 사람의 제출은 **받은 시각 이후 접수분만** 판정한다. 받기 전에 미리 친 단어는 무효.
- **동시 입력:** 소지자만 제출할 수 있어 동시 경쟁은 없다. 같은 사람은 0.3초 간격 이상만 받는다(연타 방지). 비소지자 제출은 무효·무감점.
- **이미 쓴 단어:** 경기 전체 기준. 동형어는 한 단어.
- **이탈:** 소지자가 **이탈 확정**되면 그 사람에게 폭사 1회를 기록하고 라운드를 끝낸다 (이탈로 폭탄을 피할 수 없게). 이탈 확정 전(재접속 유예 10초) 소지 중이면 계속 소지자이며 도화선도 흐른다. 비소지자 이탈은 전달 대상에서만 빠지고 점수는 유지.
- **재접속:** 같은 게임에 돌아오면 폭사 수·통과 단어 수를 복원한다. 도화선 값은 재접속 응답에도 넣지 않는다.
- **3명 미만:** 진행 중 라운드는 끝까지 하고 새 라운드는 시작하지 않는다 (09-4절). 누적 결과로 순위.
- **판정 데이터:** KKT 사전 스냅샷 버전을 그대로 쓰고 기록에 남긴다. 초성 조합 목록은 그 스냅샷에서 계산한 버전.
