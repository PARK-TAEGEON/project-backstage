## 한 줄 경험 / 차별점
전광판: **“합을 올려 불러라, 아니면 ‘뻥!’”** 각자 몰래 주사위 숫자(1~6) 하나를 받는다. 차례대로 **“모두의 숫자 합이 X 이상”**을 점점 올려 부르다가, 못 믿겠으면 **“뻥!”**. 전원 숫자 공개: “합계 14 — ‘15 이상’은 뻥이었다! 민수 벌점”. 채팅의 “나 6임 ㅋ”은 믿으면 안 된다.
- 차별점: 전통 주사위 블러핑 계열을 채팅 한 판 5분에 맞게 비틀었다 — 주사위 1개·합 하나만 부르기, 탈락 없음(벌점제), 차례 10초·판 60초 제한, 시간 초과면 **자동으로 +1 불러 주는** 불합리 규칙. 단어·설명형인 라이어 게임과 무관.

## 플레이 규칙
- setup: 5판. 좌석 순서 = 입장 순서. 첫 판 시작자는 무작위, 이후 판은 직전 판 벌점자가 시작.
- private_info: 판마다 서버가 각자에게 1~6 균등 무작위 숫자를 뽑아 **본인 view에만** 넣는다. 판이 끝날 때(“뻥!” 판정 후) 전원 숫자 공개.
- round_flow (판): 숫자 배정 → 시작자부터 차례(각 **10초**) → 차례인 사람은 **부르기**(전용 입력칸에 정수) 또는 **뻥!** → 뻥이면 공개·판정 → 발표 6초 → 다음 판.
  - 부르기 조건: 현재 부른 값보다 커야 한다. 첫 부르기는 **인원 + 1 이상**, 최대 **6 × 인원**.
  - 첫 차례에는 뻥 불가(부른 값이 없음). 현재 값이 6 × 인원이면 다음 사람은 뻥만 가능.
- actions: 부르기, 뻥!, 채팅(블러핑 자유).
- win_condition / scoring / ties:
  - 뻥! 판정: 실제 합 ≥ 부른 값 → **뻥 외친 사람 벌점 1** (“괜히 의심”). 실제 합 < 부른 값 → **마지막으로 부른 사람 벌점 1** (“뻥쟁이”).
  - 최종: 벌점 적은 순, 동률은 공동 순위.
- end_condition / timeout / no_response:
  - **차례 시간 초과:** 서버가 “현재 값 + 1”을 자동으로 불러 준다(“민수님 대신 +1 불러 드렸습니다”). 현재 값이 최대라 올릴 수 없으면 자동 뻥.
  - **판 제한 60초:** 도달하면 그때 차례인 사람이 자동으로 뻥(부른 값이 없으면 판 무효).
  - 5판 뒤 종료.
- reveal: 전원 숫자를 한 번에 펼치고 합계를 크게 → “💥 뻥쟁이: 민수 (‘15 이상’ / 실제 14)” 또는 “🙈 괜히 의심: 지수”. 최종 “뻥쟁이왕”, “의심병” 타이틀 [제안].
- replay_variation: 숫자가 매번 무작위, 사람마다 부르는 버릇이 읽힌다.

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. CALL 고유 사항:
- **마감:** 차례 `시작 ≤ 접수 < 시작+10초`, 판 전체 `판 시작 ≤ 접수 < 판 시작+60초`. 차례가 아닌 사람의 부르기·뻥은 무효(감점 없음). 차례 마감과 판 마감이 겹치면 판 마감 처리(자동 뻥) 우선.
- **한 번만 적용:** 요청 ID로 중복 무시. 뻥 판정과 벌점은 한 번에 확정.
- **동률:** 판 안에는 동률 없음(합 비교). 최종 벌점 동률은 공동 순위.
- **이탈:** 판 시작 때 배정된 숫자는 이탈해도 **그 판 합계에 포함**한다. 이탈 확정된 사람 차례는 건너뛰고, 그 사람이 마지막으로 부른 값에 뻥이 걸리면 벌점도 받는다(이탈로 피할 수 없게). 다음 판은 참가 중인 사람만으로 배정. 다음 판 전 3명 미만이면 누적 벌점으로 종료.
- **재접속:** 같은 판에 돌아오면 자기 숫자와 벌점을 복원(본인에게만).
- **3명:** 위 점검 참고.
- **비밀 정보 전달:** 각자의 숫자는 본인 view에만, 재접속 응답도 본인에게만. 판정 결과 잠금 뒤에만 전원 숫자·합계를 공개한다. 합계나 “참이 될지” 힌트를 공개 전에 어떤 view에도 넣지 않는다.
