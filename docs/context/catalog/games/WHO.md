## 게임 설명 (한 줄) [제안]
> 10초 안에 한 명을 찍어라 — 1위는 “포브스 선정”으로 발표된다!

게임 설명은 한 줄이면 충분하다 (DEC-13). 세세한 규칙은 미리 안내하지 않고, 필요한 순간에 화면이 알려 준다 (08-UI-NOTES “즉석 안내”). 전광판에 그대로 쓴다.

## 한 줄 경험
“IQ가 두 자리일 것 같은 사람은?” 10초 안에 한 명을 지목하고, 당선자는 **“포브스 선정 ‘IQ가 두 자리일 것 같은 사람’ 1위”**로 발표된다. 점수는 거들 뿐, 발표 순간의 웃음이 목표다.

## 설계 목표 [확정]
**도파민만 쫓는다.** 점수는 재미로만 두고, 점수 균형이나 전략성은 다듬지 않는다. 판단 기준은 “발표 순간이 웃긴가”, “한 판 더 하고 싶은가”다.

## 규칙 [확정]
- **7라운드.** 라운드마다 “가장 ~할 것 같은 사람은?” 질문 하나.
- 각자 **10초 안에 플레이어 한 명을 지목**한다.
- 가장 많이 지목된 사람(당선자)을 발표한다: **“포브스 선정 ‘○○○일 것 같은 사람’ 1위 — 민수”**
- 점수 (재미용): 나쁜 질문 당선 +1점 (위로 ㅜㅜ), 좋은 질문 당선 −1점. 7라운드 합산.
- 좋은 질문 / 나쁜 질문 구분은 **화면에 표시하지 않는다.** 누가 봐도 대충 안다. 구분은 점수 계산용으로 목록에만 둔다.
- **투표자는 공개하지 않는다.** 득표 수만 보여준다.

## 진행 세부 [기본값·가설]
- 자기 자신은 지목할 수 없다.
- 10초 안에 지목하지 않으면 그 라운드 기권. **라운드당 첫 표 1개로 확정, 변경 불가** (H-4).
- 동률: 공동 1위 모두 발표 (“포브스 선정 공동 1위”). 점수도 모두에게.
- **유효표 0개**(전원 기권): 당선자 없음, 점수 변화 없음, 다음 라운드 (H-3).
- 발표 뒤 **5초 고정** 채팅 반응 시간 후 자동 진행 — “아니 내가 왜 IQ 두 자리야”.
- 마지막에 7개 타이틀을 사람별로 모아 보여준다 — “민수: 포브스 선정 3관왕 (IQ 두 자리, 약속 지각왕, 읽씹 1위)”. [제안]

## 질문 목록 [확정: AI 대신 미리 만든 목록]
- **포괄적인 질문만** 쓴다 [확정]: 성별·나이·직업·연애 여부·음주 여부·가족 구성 등에 따라 답할 수 없거나 소외되는 질문은 넣지 않는다. 누구에게 붙어도 말이 되는 질문이어야 한다.
- 항상 금지: 성적인 내용, 외모 비하, 질병, 가족사, 차별·혐오.
- [기본값·가설] 시작 투표(DEC-06) 유지: 민감한 주제 허용 여부를 익명 투표하고 **만장일치일 때만** 🌶 매운맛 질문을 섞는다.
- [기본값·가설] 한 판 7문항은 좋은 / 나쁜 질문을 섞는다 (나쁜 4 · 좋은 3).

### 질문 초안 (구분은 내부용, 화면에는 표시하지 않음)
좋은 질문 (당선 −1)
- 제일 먼저 부자 될 것 같은 사람은?
- 좀비 사태에서 끝까지 살아남을 것 같은 사람은?
- 비밀을 제일 잘 지킬 것 같은 사람은?
- 무인도에 떨어지면 리더가 될 것 같은 사람은?
- 몰래 선행하고 다닐 것 같은 사람은?
- 노래방 점수 제일 높을 것 같은 사람은?
- 위기 상황에서 제일 침착할 것 같은 사람은?
- 퀴즈쇼에 나가면 우승할 것 같은 사람은?
- 제일 먼저 유명해질 것 같은 사람은?

나쁜 질문 (당선 +1)
- IQ가 두 자리일 것 같은 사람은?
- 약속에 제일 늦을 것 같은 사람은?
- 단톡방 읽씹 1위일 것 같은 사람은?
- 좀비 사태 때 제일 먼저 감염될 것 같은 사람은?
- 계획만 세우고 절대 안 할 것 같은 사람은?
- 셀카 100장 찍고 1장 올릴 것 같은 사람은?
- 길 잃고도 아는 척할 것 같은 사람은?
- 알람 10개 맞추고 다 끌 것 같은 사람은?
- 택배 박스 한 달 방치할 것 같은 사람은?
- 우산을 제일 많이 잃어버렸을 것 같은 사람은?

🌶 매운맛 (만장일치 허용 시)
- 검색 기록 절대 못 보여줄 것 같은 사람은? (나쁜)
- 흑역사 사진 제일 많을 것 같은 사람은? (나쁜)
- 혼자 있을 때 제일 이상할 것 같은 사람은? (나쁜)

0.2 초안에서 뺀 질문 (포괄성 기준 위반): 월급날 거지(직업 전제), 부모님께 효도(가족 구성 전제), 연애 경험·전 애인 연락(연애 여부 전제), 술 흑역사(나이·음주 전제).

## 최소 인원 (4명)
- 3명은 지원하지 않는다 (DEC-13). 3명이면 각자 2명 중 1명을 고르므로 1-1-1 동률이 라운드의 약 25%이고, 득표 수만으로 누가 누구를 찍었는지 확정되어 비공개가 성립하지 않는다.
- 4명에서는 각자 3명 중 1명을 고른다. 4명 테스트가 필수이며, 4명일 때 득표 수로 선택이 얼마나 추론되는지 관찰한다.

## 알려진 위험
- **특정인 몰아가기:** 한 사람이 계속 나쁜 타이틀을 받을 수 있다 (헌법 8조) → 투표자 비공개, 시작 투표로 완화. 사람 테스트에서 불쾌감 관찰 필수.
- **이름 사용:** ‘포브스’는 실제 잡지 브랜드다. 친구 테스트에는 문제없지만, 공개 서비스로 낼 때는 상표 문제를 확인한다 (06-EXPANSION의 브랜드 사용 별도 결정과 연결).

## 미정 항목
- 공개 서비스에서 ‘포브스’ 이름 사용 가능 여부

## 판정·처리 규약 (ASTRA 1차 반영) [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. WHO 고유 사항:
- **시작 투표 (H-1):** 10초 제한. 무응답·이탈은 “허용 안 함”으로 센다. 마감 때 **전원이 명시적으로 찬성**한 경우만 매운맛을 켜고 바로 1라운드.
- **비공개의 범위 (H-2):** “투표자 비공개”는 **누가 누구를 찍었는지 직접 보여주지 않는다**는 뜻이다. 4명처럼 적은 인원에서 득표 수로 선택이 일부 추론되는 것은 막지 않는다 (득표 수 공개를 유지하는 한 막을 수 없음).
- **후보 명단 (H-4):** 라운드 시작 시 고정. 투표 중 이탈한 사람도 그 라운드 후보로 남고 이미 받은 표도 유지. 다음 라운드 전에 인원을 다시 계산하고, **4명 미만이면 새 라운드를 시작하지 않고 경기 종료**(최소 인원 미달).
- **최종 결과 (H-5):** 합계 점수 순으로 보여주고 사람별 타이틀을 모아 발표한다. 1위 표시는 재미용, 동률은 공동.
- **질문:** 한 판 안에서 같은 질문 반복 없음.
