## 한 줄 경험 / 차별점
전광판: **“터지기 전에 손 떼!”** 가운데 풍선이 커지며 숫자가 오른다. 아무 때나 **손 떼기**를 누르면 그때 크기가 내 점수. 풍선은 **아무도 모르는 순간** 터지고, 그때까지 잡고 있던 사람은 0점. 누가 손 뗐는지는 안 보이고 **“잡고 있는 사람 3명”** 숫자만 보인다 — 채팅의 “나 아직 잡고 있음 ㅋ”이 진짜인지 모른다. **“펑! 민수·지수 폭사”** / 전원 손 떼면 “원래 터질 크기: 42” 공개에 비명.
- 차별점: 눈치게임(NUNCHI)은 숫자 충돌·타이밍 경쟁이고, POP은 **각자 욕심 조절 + 남의 눈치**다. 반응 속도가 아니라 “언제 멈출까” 심리전.
- 순발력 계열과 겹칠 수 있는 지점: 폭발 직전 0.1초 차이는 서버 접수 시각으로만 판정한다. 다른 디자이너의 “폭탄 돌리기”류와 겹치면 오케스트레이터가 정리.

## 플레이 규칙
- setup: 점수 0. 5라운드.
- private_info: 라운드마다 서버가 **터지는 시각 T를 4~20초 사이 균등 무작위**로 뽑아 서버에만 둔다(누구에게도 보내지 않음). 각자의 손 뗀 여부·점수는 본인만 안다. 다른 사람에게는 “잡고 있는 사람 수”만.
- round_flow: 3·2·1 → 풍선 시작. **크기 = 0.5초마다 +1**(서버 시작 시각 기준, 화면은 시작 시각으로 그린다). 손 떼기 버튼 1회. T 도달 또는 전원 손 떼면 라운드 종료 → 발표 6초.
- actions: 손 떼기(라운드당 1회, 취소 불가), 채팅(블러핑 자유).
- win_condition / scoring / ties:
  - 손 뗀 순간의 크기 = 그 라운드 점수. 터질 때 잡고 있으면 0.
  - **강심장 보너스:** 터지기 전에 손 뗀 사람 중 가장 늦게 뗀 사람 **+5**(같은 크기로 공동이면 모두).
  - 최종: 합계 순, 동률은 공동 순위.
- end_condition / timeout / no_response: T에 반드시 터진다(최대 20초). 아무것도 안 누르면 폭사. 5라운드 뒤 종료.
- reveal: 전광판 “💥 펑! (크기 31)” → 손 뗀 순서대로 “철수 12 · 영희 25 · 🦁강심장 지수 29” → 폭사자 명단. 전원 손 뗀 경우 “원래 터질 크기: 42”. 최종 “폭사왕”(폭사 최다) 타이틀 [제안].
- replay_variation: T가 매번 무작위, 사람들의 욕심 패턴이 판마다 드러난다.

## 구현 / 실패
- common_components: 중앙 카운트다운, 전광판, 게임 전용 버튼(action), [현재 순위]. 효과음(풍선 커지는 소리·펑)은 선택 — 넣으면 음소거 버튼 필수(08-UI-NOTES).
- ai_call_points / AI 사용 이유: 없음.
- judgment_criteria / deterministic_rules: 손 떼기 접수 시각 t가 `시작 ≤ t < T`면 유효, 점수 = floor((t − 시작) / 0.5초). `t ≥ T`면 폭사.
- ai_failure_fallback: 해당 없음.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - 네트워크 지연: 폭발 직전에 누른 사람이 억울할 수 있음 → 서버 접수 기준 명시, 사람 테스트 관찰.
  - 클라이언트가 T를 추측할 경로: 서버가 폭발 전까지 라운드 종료 신호를 보내지 않으므로 없다. 전원 손 뗀 조기 종료 때만 T 공개.
  - 늘 1초에 손 떼는 안전 전략 → 점수 낮음, 강심장 보너스로 견제.
- social_risk / 소외 방지: 폭사해도 다음 라운드에 바로 참여. 탈락 없음.
- three_player_check: 결정이 각자 독립이라 3명에서도 규칙 그대로 성립. “잡고 있는 사람 수”가 3→2로 바뀌면 나를 뺀 둘 중 누가 뗐는지 모르는 추리가 생긴다. 강심장 보너스 경쟁은 인원이 적을수록 치열 [가설].
- 기타 인원 제약: 없음.

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. POP 고유 사항:
- **마감:** 폭발 시각 T가 마감이다. `시작 ≤ 접수 < T`만 유효(09 1절). 같은 시각 접수는 접수 번호 순이지만 점수는 시각으로만 계산하므로 순서가 결과를 바꾸지 않는다.
- **한 번만 적용:** 손 떼기는 라운드당 1회, 요청 ID로 중복 무시.
- **동률:** 강심장 공동 → 모두 +5. 최종 동률 → 공동 순위.
- **이탈:** 손 떼지 않은 채 연결이 끊기면 계속 잡고 있는 것으로 본다(이탈로 폭사를 피할 수 없게). 이탈자 점수 유지. 다음 라운드 전 3명 미만이면 누적 점수로 종료.
- **재접속:** 같은 라운드에 돌아오면 손 뗀 여부·점수를 복원, 아직 안 뗐으면 계속 누를 수 있다.
- **3명:** 위 점검 참고.
- **비밀 정보 전달:** T는 서버 밖으로 나가지 않는다(폭발 후 또는 전원 손 뗀 뒤 결과 잠금 다음에만 공개). 다른 사람의 손 뗀 여부·점수는 view에 넣지 않고 “잡고 있는 사람 수”만 넣는다.
