## 한 줄 경험
1부터 차례로 숫자를 채팅에 친다. 같은 숫자가 겹치면 탈락, 끝까지 못 친 사람도 탈락. 설명이 필요 없는 게임.

## 규칙 [확정]
- **3라운드.**
- 라운드마다 화면 **중앙에 크게 3 · 2 · 1** 카운트다운을 보여준 뒤 시작한다.
- 같은 숫자를 **동시에** 친 사람은 모두 탈락. 동시 기준은 **0.01초**.
- 마지막까지 숫자를 치지 못한 사람도 탈락.

## 판정 세부 [기본값·가설]
- 시각 기준: **서버 도착 시각**. 모든 참가자의 판정 시계를 하나로 통일한다.
- 숫자 입력: 채팅 메시지가 **숫자만** 있을 때 제출로 본다 (“3”, “3!” 불인정 여부는 미정). 다른 채팅(“ㅋㅋ”, “아 뭐야”)은 자유.
- 1부터 차례로 올라간다. 다음 차례 숫자를 가장 먼저 친 사람이 그 숫자를 차지한다.
- 이미 차지된 숫자를 늦게 친 사람(0.01초보다 늦음)은 **혼자 탈락**한다.
- 다음 차례가 아닌 숫자(예: 3 차례에 5)를 치면 탈락.
- 카운트다운 중에 숫자를 치면 **부정출발 탈락**.
- 한 사람은 라운드당 숫자 하나만 칠 수 있다.
- 라운드 종료: 인원이 N명이면 N−1까지 차지되거나 남은 사람이 1명이 될 때, 못 친 사람은 탈락.
- 제한 시간: 한동안 아무도 안 치면 [기본값·가설: 10초] 그때까지 못 친 사람 전원 탈락.

## 0.01초 기준에 대한 주의 [확인 필요]
- 인터넷 지연 편차는 보통 수십~수백 ms라서, **0.01초(10ms) 안에 두 메시지가 서버에 도착하는 일은 거의 없다.** 즉 “둘 다 동시 탈락”은 드물고, 대부분 **먼저 도착한 사람이 숫자를 차지하고 늦은 사람만 혼자 탈락**한다.
- 이 경우 “누가 먼저인가”는 손가락보다 **인터넷 속도**가 가를 수 있다 (와이파이 vs 유선, 서버와의 거리).
- 사용자 결정(0.01초)을 기본값으로 두되, 사람 테스트에서 **0.01초 / 0.3초 / 0.5초**를 비교해 “동시에 걸렸다!”는 순간이 충분히 나오는지 본다.
- 판정 표시에 두 사람의 시간 차를 보여주면 납득과 웃음을 함께 얻을 수 있다 — “💥 민수 · 지민 동시! (0.004초 차)”. [제안]

## 점수 / 결과 [기본값·가설]
- 점수는 재미용 (포브스와 같은 도파민 우선).
- 라운드마다 탈락자를 발표. 3라운드 후 탈락 횟수가 가장 많은 사람을 **“오늘의 눈치 없는 사람”**으로 발표.

## UI · 사운드
- 3 · 2 · 1 카운트다운은 중앙에 크게 [확정]. 공통 UI 메모(08-UI-NOTES)의 카운트다운 부품을 쓴다.
- [제안] 숫자가 차지될 때마다 채팅창 대신 중앙에 크게 띄우기, 겹침 순간 효과음. 사운드 실험은 쿵쿵따 결과를 본 뒤 확장 여부를 결정한다.

## 3명 점검
- 3명이면 숫자 1, 2만 차지하면 끝나 라운드가 몇 초 만에 끝난다. 겹칠 확률도 낮다 → 3명에서 재미가 나는지 테스트 필수.

## 알려진 위험
- **지연 불공정:** 위 “0.01초 기준” 참고. 모바일 데이터 사용자가 계속 불리할 수 있다.
- **기다리기 전략:** 아무도 먼저 안 치고 눈치만 보면 제한 시간이 필요하다 → 10초 기본값.
- **재접속:** 라운드 중 끊기면 그 라운드는 “못 친 사람” 처리 [기본값·가설].
