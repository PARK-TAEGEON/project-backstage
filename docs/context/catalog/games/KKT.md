## 한 줄 경험
순서대로 **세 글자 단어**를 앞 단어의 끝 글자로 이어 간다. 시간에 쫓기다 사전에 없는 단어를 지어내면 바로 제지당하고, 기다리는 사람들은 채팅으로 마음껏 방해한다.

## 규칙 [확정]
- 단어는 **정확히 세 글자**, 앞 단어의 **마지막 글자로 시작**해야 한다.
- **두음법칙 적용:** 앞 단어가 ‘력’으로 끝나면 ‘역’으로, ‘녀’면 ‘여’로 시작해도 된다.
- **한방단어 허용:** 이어 갈 단어가 없는 글자로 끝나는 단어도 첫 차례부터 쓸 수 있다.
- **사전에 없는 단어**는 제지한다.
- **차례 시간은 점점 줄어든다** (DEC-17): 10초에서 시작해 경기에서 단어가 하나 이어질 때마다 0.25초씩 줄고, 최소 3초. [값은 기본값·가설 — 사람 테스트로 조정]
- **틀린 단어는 탈락이 아니다** (DEC-17): 사전에 없음·세 글자 아님·첫 글자 불일치·이미 나온 단어는 “없는 단어예요! 다시!”로 알리고, **차례 시간 안에 다시 시도**한다. 시간은 계속 흐른다.
- **탈락은 시간 초과(와 이탈)뿐.** 차례 시간 안에 맞는 단어를 못 대면 바로 탈락.

## 경기 구조 [확정]
- **한 명이 탈락할 때마다 한 라운드**가 끝난다. 한 명만 남으면 경기 종료 (N명이면 N−1라운드).
- 순위: 마지막까지 남은 사람이 1위, 처음 탈락한 사람이 꼴찌 — 탈락 순서의 역순.
- 점수: 순위에 따라 점수를 준다. [미정 — 나중에 조정] 임시값: N명일 때 1위 N점 … 꼴찌 1점.

## 진행 [기본값·가설]
- 순서: 경기 시작 시 무작위로 정하고, 탈락자는 순서에서 빠진다.
- 첫 단어: 시스템이 무작위 시작 글자를 제시한다. 새 라운드도 새 시작 글자로 시작하며, 탈락자 다음 사람이 먼저 한다.
- 이미 나온 단어 금지는 경기 전체에 적용.
- 입력 [확정]: 단어는 **전용 입력칸**으로 제출하고, 채팅은 누구나 자유롭게 한다. 차례가 아닌 사람의 채팅은 판정하지 않는다 → 기다리는 사람이 채팅으로 방해·조롱할 수 있다.
- 실패 이유를 채팅에 공지한다 (예: “❌ 지민님 ‘사과즙’… 사전에 없는 단어입니다”).
- 탈락자는 관전하며 채팅 가능.

## 사운드 실험 [확정: 쿵쿵따에서만 실험]
리듬감 있는 비트와 찰진 효과음을 넣어 본다. 다른 게임에는 적용하지 않는다.
- [제안·가설] 비트: “쿵·쿵·따” 박자에 차례 타이머를 맞춘다 — 차례 시간이 줄면 박자도 빨라진다. 화면 타이머도 박자에 맞춰 움직인다.
- [제안·가설] 효과음: 단어 통과 “따!”, 탈락 “땡”, 한방단어 성공 시 폭발음, 마지막 1명 남을 때 짧은 팡파르.
- 음원: 직접 만들거나 저작권 문제 없는 음원(CC0 등)만 쓴다. Web Audio로 코드에서 합성하는 방법도 가능.
- 모바일 브라우저는 사용자가 화면을 한 번 눌러야 소리를 낼 수 있다 → Ready 버튼을 누를 때 오디오를 켠다.
- 음소거 버튼 필수 (공공장소 플레이).
- 검증: 사람 테스트에서 **소리 켬 / 끔**을 비교한다. 소리가 긴장감·웃음을 늘리는지, 짧아지는 시간 판단을 방해하는지 관찰.

## 단어 검증
- AI가 아닌 **사전 데이터**로 코드가 판정한다. AI는 존재하지 않는 단어를 있다고 하거나 반대로 판단할 수 있어 판정 기준으로 쓰지 않는다.
- 데이터: 국립국어원 표준국어대사전(표제어 약 42만) 또는 우리말샘. 게임 중 API를 호출하지 않고, 내려받은 목록에서 **세 글자 단어만 뽑아 서버에 둔다** (빠르고 무료).
- 포함 범위 [확정]: **전체** — 방언·옛말·북한어 포함.
- [기본값·가설] 품사 제한 없음. 표제어의 붙임표·기호는 제거하고 한글 세 글자만 남긴다.
- 한방단어 목록과 두음법칙 변환표는 같은 데이터에서 미리 계산한다.
- 라이선스: 표준국어대사전은 CC BY-SA — 출처 표기와 동일조건 변경허락 조건을 확인한다.
- 세 글자 단어 수: 공식 통계 미확인. 데이터를 받은 뒤 직접 센다.

## 구현 메모 (프로토타입, DEC-16) [기본값·가설]
- 사전: 표준국어대사전 XML 스냅샷 `stdict-2019-06-25`에서 `word_unit = 단어`인 표제어 중 한글 세 글자 **96,217개**. 구·관용구·속담은 단어가 아니라서 뺀다. 출처·라이선스는 `apps/server/dict/README.md`, 게임 화면 하단에 출처 표시.
- 두음법칙 표: 한글 맞춤법 제10~12항 (`dueum-1`) — ㄴ→ㅇ(녀·뇨·뉴·니), ㄹ→ㅇ(랴·려·례·료·류·리), ㄹ→ㄴ(라·래·로·뢰·루·르). 받침이 있어도 적용(력→역, 락→낙).
- 시작 글자: 사전에서 안 쓴 단어를 무작위로 골라 그 첫 글자. 이어 갈 답이 30개 이상인 글자를 우선한다.
- 한방단어: 제출 순간 “그 끝 글자로 이을 안 쓴 단어가 0개”면 한방단어로 표시하고 폭발음을 낸다.
- **1:1 결승:** 09-ENGINE-RULES 4절(3명 미만이면 새 라운드 없음)의 예외. 쿵쿵따는 스펙대로 1명 남을 때까지 진행한다.
- 이탈: 차례가 아닌 사람이 나가면 탈락 기록만 하고 차례는 계속. 플레이 탈락 없이 나간 사람만으로 끝나면 경기 중단(aborted)으로 기록.
- 재접속 유예(10초) 중인 사람에게 차례가 오면 차례 시간이 지나면 시간 초과로 탈락한다.
- 입력칸은 생존자에게 항상 보이고, 제출 버튼은 내 차례에만 켜진다 (모바일에서 키보드를 켜 둔 채 기다리게).
- 사운드: Web Audio 합성(음원 파일 없음). 차례 시간 = “쿵·쿵·따” 3마디(시간이 줄면 박자가 빨라짐), 틀린 단어 “삑”, 화면에 박자 불빛 9칸. 통과 “따!”, 탈락 “땡”, 한방 폭발음, 마지막 1명 팡파르. 첫 클릭 때 오디오를 켜고, 음소거 버튼은 이 브라우저에 저장.

## 3명 점검
- 3명이면 2라운드로 경기가 매우 짧다 → 연속 판(Play Again) 흐름이 중요. 1:1 결승 구간은 차례 시간이 이미 줄어 있어 짧을 것으로 예상, 테스트로 확인.

## 알려진 위험
- **탈락자 소외:** 첫 탈락자는 경기 끝까지 관전한다 → 채팅 방해가 참여 수단. 차례 시간이 갈수록 줄어 대기 시간은 짧을 것으로 예상 [가설].
- **한방단어 난사:** 첫 차례부터 한방단어가 허용되어 순서 운이 크다. 의도된 불합리함 [확정] — 테스트에서 짜증인지 웃음인지 관찰.
- **전체 사전의 낯선 단어:** 방언·옛말·북한어까지 허용해 “그게 단어야?”가 자주 나온다 → 통과한 단어의 뜻을 한 줄 보여주면 웃음 포인트 [제안].
- **실력 편차:** 단어를 많이 아는 사람이 계속 이긴다 → 점수 방식 조정 때 함께 검토.

## 판정·처리 규약 (ASTRA 1차 반영) [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. KKT 고유 사항:
- **사전 고정 (K-1):** 국립국어원 **표준국어대사전 1종**, 내려받은 날짜로 스냅샷 버전을 붙인다. 확정된 전체 범위(방언·옛말·북한어 포함)는 유지.
  - 표제어 정규화: NFC, 붙임표·기호·공백·어깨번호 제거 후 **한글 음절 정확히 3개**만 남긴다. 같은 글자의 동형어는 한 단어로 본다.
  - 제출 단어도 같은 정규화 함수로 처리한다.
- **두음법칙 표:** `끝 음절 → 허용 시작 음절 집합` 표를 따로 만들고 버전을 붙인다. 방향은 **앞 단어 끝 음절의 두음법칙 형태를 허용**하는 쪽만 (력 → 력·역, 녀 → 녀·여, 라 → 라·나 등). 역방향(역 → 력)은 허용하지 않는다.
- **시작 글자 (K-2):** 사전에 **아직 안 쓴 답이 1개 이상 있는 글자**에서만 뽑는다. 뽑을 글자가 하나도 없으면 경기를 끝내고 남은 생존자를 공동 1위로 한다 (사실상 발생하지 않음).
- **제출 시각 (K-3, 0.4 수정):** `차례 시작 ≤ 접수 < 차례 시작 + 차례 시간`인 제출만 판정한다. 틀리면 거절하고 같은 차례에 다시 받는다. 같은 사람의 제출은 한 차례 안에서 0.3초 간격 이상만 받는다(연타 방지). 차례가 아닌 사람의 제출은 무효. 시간 초과 탈락 때 마지막 틀린 시도를 기록한다.
- **사전 장애:** 사전을 불러오지 못하면 참가자 탈락이 아니라 경기 중단.
- **이탈 (K-4):** 이탈 확정 순서대로 탈락자로 기록한다 (그 시점의 탈락 순위를 받음). 차례인 사람이 이탈하면 그 차례 탈락. 여러 명 동시 이탈은 접수 번호 순. **재접속해도 탈락은 취소되지 않는다.** 전원 이탈 시 경기 중단 기록.
- **첫 차례:** 경기 시작 시 무작위로 정한 순서의 첫 사람. 새 라운드는 탈락자 다음 사람부터.
- **순위 점수의 N:** 경기 시작 인원.
