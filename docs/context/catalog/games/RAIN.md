## 한 줄 경험 / 차별점
화면 위에서 단어가 쏟아진다. 모두 같은 단어를 노리고, 0.1초 차이로 “뺏겼다!”. 급하게 치다 빨간 **함정 단어**를 쳐서 −3점.
- 기존 5개와 차이: 차례·비밀·채팅 득점이 없는 **공용 화면 쟁탈전**. 한 판에 목표가 여러 개 동시에 떠 있다.

## 플레이 규칙
- setup: 단어 목록에서 이번 판 단어를 무작위 순서로 뽑는다.
- private_info: 없음. 단어는 등장 순간 모두에게 동시에 보낸다. 다음 단어를 미리 보내지 않는다.
- round_flow:
  1. 중앙 3·2·1 → 단어가 **1초마다 1개** 위에서 나타나 **7초 동안** 떨어진다(바닥에 닿으면 사라짐).
  2. 누구든 전용 입력칸에 떠 있는 단어를 정확히 치면 그 단어를 가져간다 — 단어가 모두의 화면에서 터지며 “민수 +1”.
  3. 75초 뒤 라운드 종료 → [현재 순위] → 2라운드.
- 단어 종류: **일반**(흰색) +1, **황금**(노랑, 10%) +3, **함정**(빨강, 10%) −3. 함정 단어는 같은 시각 화면에 있는 일반 단어와 한 글자만 다른 짝으로 나온다(예: 일반 ‘호박죽’ 옆 함정 ‘호박줄’) [가설].
- actions: 전용 입력칸 제출. 채팅은 자유(판정 없음). 제출한 글자는 채팅에 올라가지 않는다.
- win_condition / scoring / ties: 2라운드 합계 순. 같으면 공동 순위.
- end_condition / timeout / no_response: 라운드는 고정 75초. 아무도 안 쳐도 끝난다.
- reveal: 라운드 끝 [현재 순위](08-UI-NOTES 부품). 게임 끝에 **“함정 최다 피해자”**와 가장 많이 뺏긴 단어(0.3초 안에 다른 사람도 친 단어)를 전광판에.
- replay_variation: 단어 순서·황금/함정 배치가 매번 무작위.

## 콘텐츠 (예시 20개 — 구현 때 확장)
2~4음절, 띄어쓰기 없는 일반 명사. 상표·인물·특정 집단 전제 없음. `wordcore` 단어 풀(`pools-2`)을 재사용해도 된다.
- 일반: 호박죽, 고슴도치, 수박씨, 눈사람, 우체통, 해바라기, 미끄럼틀, 도토리, 비눗방울, 솜사탕, 달팽이, 종이비행기, 방울토마토, 무지개, 튀김옷, 모래성
- 함정 짝 예시: 호박죽→호박줄, 도토리→도토라, 달팽이→딸팽이, 솜사탕→솜사랑
- 황금은 일반 단어 중 무작위로 색만 바꾼다.

## 구현 / 실패
- common_components: 전광판, 중앙 카운트다운, 전용 입력칸, [현재 순위] 표, 정규화 함수. 새 부품: 떨어지는 단어 판(서버가 등장 시각·수명만 보내고 위치 애니메이션은 웹이 계산).
- ai_call_points / AI 사용 이유: 없음.
- judgment_criteria / deterministic_rules: 제출을 정규화(09-7절)하고 공백을 뺀 뒤, 접수 시각에 **살아 있는** 단어(`등장 ≤ 접수 < 등장 + 7초`, 아직 안 가져감)와 정확히 일치하면 그 단어를 가져간다. 일치 없음 → 아무 일 없음(감점 없음).
- ai_failure_fallback: 해당 없음.
- disconnect / reconnect / player_count_change: 아래 판정·처리 규약.
- failure_cases / exploit_cases:
  - 추측 난사(아직 안 뜬 단어 미리 치기): 등장 전 접수는 일치 대상이 없어 무의미. 제출은 사람당 0.2초 간격 이상만 받는다.
  - 같은 글자 단어 두 개: 화면에 같은 글자 단어가 떠 있는 동안은 같은 단어를 새로 띄우지 않는다.
  - 기기 격차: PC 키보드가 모바일보다 유리하다 → 알려진 위험. 단어를 짧게(2~4음절) 유지. 사람 테스트에서 기기별 점수 차 관찰.
- social_risk / 소외 방지: 타자 느린 사람도 황금 한 방(+3)과 남의 함정 실수로 역전 여지. 뒤처진 사람의 포기 여부 관찰.
- three_player_check: 쟁탈 대상이 공용 단어라 3명이면 1인당 가져갈 단어가 많아질 뿐 규칙은 그대로 성립. 역할·다수결 없음. 동률은 공동 순위.
- 기타 인원 제약: 8명이면 뺏기 경쟁이 심해 0점인 사람이 나올 수 있다 [가설] — 테스트 관찰.

## 판정·처리 규약 [기본값·가설]
[공통 판정 규약](../../09-ENGINE-RULES.md)을 따른다. RAIN 고유 사항:
- **시간 경계:** 단어별 유효 구간 `등장 ≤ 접수 < 등장 + 7초`. 라운드 구간 `시작 ≤ 접수 < 시작 + 75초`; 라운드 마감 뒤 접수는 무효. 마감 직전 등장한 단어도 라운드 마감에서 함께 사라진다.
- **동시 입력:** 같은 단어는 **접수 번호가 가장 빠른 한 명**만 가져간다. 뒤늦은 일치 제출은 “한 발 늦음” 표시만(점수 없음, 감점 없음). 뺏김 기록: 가져간 접수 후 0.3초 안에 같은 단어를 친 사람 수.
- **함정:** 함정 단어도 가져가는 규칙은 같다(첫 접수자만 −3, 단어 사라짐).
- **이탈:** 점수 유지, 이탈자는 제출만 멈춘다. 재접속하면 점수 복원, 현재 떠 있는 단어 목록과 남은 수명을 다시 받는다.
- **3명 미만:** 진행 중 라운드는 끝까지, 새 라운드 없음 → 누적 점수로 순위 (09-4절).
- **판정 데이터:** 단어·함정 짝 목록에 버전(`rain-words-1`).
