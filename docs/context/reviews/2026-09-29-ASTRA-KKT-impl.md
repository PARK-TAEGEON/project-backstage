- 대상: 쿵쿵따 KKT 0.3 프로토타입 — 서버(`apps/server/src/games/kkt/`), 사전 데이터(`apps/server/dict/`), 웹(`apps/web/src/games/kkt/`), 테스트
- **판정: pass (치명 0건)** — 종료 불가·참여 불가·비밀 누출 없음

## 확인한 것
- 한방단어 뒤 다음 사람은 5초 시간 초과로 탈락 → 막히지 않음. 시작 글자는 안 쓴 답이 있는 글자에서만, 못 뽑으면 공동 1위로 종료.
- 5초 경계 `시작 ≤ 접수 < 시작+5초`, 타이머가 일찍 울리면 재예약. 접수 시각은 소켓 핸들러 첫 줄.
- 차례인 사람·아닌 사람의 이탈, 라운드 소개·결과 중 이탈, 1:1 결승, 1명 남을 때 종료.
- 재접속 유예 중 차례 → 5초 뒤 시간 초과, 이후 이탈 확정은 무시 → 무한 대기 없음.
- 사전 로드 실패 → 경기 중단(aborted), 다음 게임으로 진행.
- 한국어 IME Enter 제출·중복 제출 방지(화면 잠금 + 서버 차례 검사 + 요청 ID 중복 제거).
- 제출 정규화(NFC·공백 제거)와 사전 정규화 일치. 사전 파일 96,217줄 전부 NFC 한글 세 음절, 중복 0.
- 비밀 정보 없음 — 모든 사람에게 같은 공개 상태만 보냄.

## 비치명 지적과 처리
1. 나머지가 모두 나가서 끝나면 정상 우승으로 기록됨(09 4절 “전원 이탈 = 경기 중단”과 다름) → 플레이 탈락 없이 나간 사람만 있으면 aborted로 기록하도록 수정, 테스트 추가.
2. 1:1 결승이 09 4절(3명 미만 새 라운드 없음)과 다름 → KKT 스펙 “구현 메모”와 DEC-16에 예외로 명시.
3. 재접속 유예 중 차례가 오면 ‘시간 초과’로 기록 → 백로그로.
4. 시작 글자 추첨 40회 실패 시 공동 1위로 끝날 여지 → 추첨 실패 시 사전 전체를 순서대로 찾도록 수정.
5. 모바일에서 포커스만으로 키보드가 안 뜰 수 있음 → 생존자에게 입력칸을 항상 보여 주도록 변경, 사람 테스트 항목으로 백로그.
6. 스펙 `implementation_status` 불일치 → prototype으로 갱신. Web Audio 생성 예외 → try/catch로 소리만 끄고 진행.
