## TRUTH v0.1 — 판정: pass
치명 문제: 없음.
- 종료: 답변 15초(미제출 시 묵비권으로 라운드 종료), 투표 25초 고정. 라운드 수는 시작 때 정해지고 이탈 확정자 차례는 건너뜀.
- 비밀: 지시는 발표자 view·재접속 응답에만. 표 수·투표자 명단은 결과 잠금 뒤. 정답이 서버 지시라 코드로 판정 가능.

비치명 메모:
- 투표자가 0명(전원 무투표)일 때 “투표한 사람 전원을 속이면 +2”가 공허 참으로 적용되는지 정의 필요 — 투표자 1명 이상일 때만으로 명시 권장.
- 발표자가 연결은 끊겼지만 이탈 확정 전(10초 유예)에 답 마감이 오면 묵비권 −1인지, 무효인지 경계 명시 — 구현 백로그.
- 질문 19번 포함 여부는 [미정]으로 남아 있음(치명 아님).

## POP v0.1 — 판정: pass
치명 문제: 없음.
- 종료: T는 4~20초라 라운드가 반드시 끝나고, 전원 손 떼면 조기 종료. 5라운드 고정.
- 비밀: T는 서버 밖으로 나가지 않고 폭발 또는 전원 손 뗀 뒤 결과 잠금 다음에만 공개. 다른 사람의 손 뗀 여부·점수는 view에 없고 “잡고 있는 사람 수”만 보임(의도된 공개 정보).
- 3명: 결정이 각자 독립이라 그대로 성립.

비치명 메모:
- 예시 “원래 터질 크기: 42”는 T 최대 20초 × 0.5초 단위 = 최대 40과 맞지 않음 — 표현 수정.
- 아무도 터지기 전에 손 떼지 않은 라운드에는 강심장 보너스가 없다는 점을 명시하면 좋음.
- 네트워크 지연 억울함은 스펙이 인지(서버 접수 기준).

## CALL v0.1 — 판정: pass
치명 문제: 없음.
- 종료: 차례 10초마다 자동 부르기/자동 뻥, 판 60초 제한으로 판이 반드시 끝남. 5판 고정.
- 비밀: 각자 숫자는 본인 view에만, 합계·참 여부 힌트는 공개 전 어떤 view에도 없음.
- 3명: 합 3~18, 첫 부르기 4 이상으로 성립. 정수는 text 입력칸으로 가능.

비치명 메모:
- 첫 차례 시간 초과 시 “현재 값 + 1”의 현재 값이 없음 — “인원 + 1(최소값)을 부른다”로 명시 권장(명시 안 해도 60초 제한으로 막히지는 않음).
- 다음 판 시작자 = 직전 판 벌점자인데, 직전 판이 무효였거나 벌점자가 이탈한 경우의 시작자 정의 필요(무작위 등) — 구현 백로그.
- 판 중 이탈로 참가 중 인원이 1명만 남을 때 자기 부른 값에 자기가 차례를 받는 상황 — 60초 제한으로 끝나지만 처리 문구 정리 필요.

## DEFUSE v0.1 — 판정: pass
치명 문제: 없음.
- 종료: 모든 단계가 고정 시간(카드 10초, 토론, 지목 12초). 카드 미제출 = 해체, 지목 무응답 = 기권, 동률·유효표 0 = 지목 실패로 정의. 해체범 전원 이탈·3명 미만 처리 있음.
- 비밀: 역할은 본인(해체범끼리)에게만, 해체반 view에 💣 버튼 자체가 없음, 제출 여부·순서·시각 비공개, 카드 단계는 전원 제출해도 조기 종료하지 않아 타이밍 신호 없음, 폭탄 결과는 폭파 장수만. 출동조는 역할과 무관하게 시작 때 무작위로 정해지고 공개 정보.
- 3명: 2인조 3개가 한 번씩이라 모든 제약(전원 최소 1회 출동, 중복 없음)이 충족됨. 해체범이 폭파하면 같은 조 1명만 확신하고 나머지 1명은 모르므로 숨은 역할이 전원에게 뻔해지지 않음. 모든 인원(3~8)에서 출동조 제약이 충족 가능함을 확인.

비치명 메모:
- 3명 점검의 “투표는 3표이고 동률이 나지 않는다”는 틀림 — A→S, S→C, C→A로 1:1:1 동률이 가능하고 이는 지목 실패(해체범 유리). 규칙상 정의는 있어 치명 아님, 점검 문구와 밸런스 관찰 항목 수정.
- 지목 투표 중 표 수·투표자 비공개가 “비밀 정보 전달” 절에 명시돼 있지 않음(카드만 명시) — 공개 단계에서 표를 공개한다고 했으므로 마감 전 비공개를 한 줄 명시 권장.
- 3명에서 해체범 이탈 시 “해체범 전원 이탈 → 해체반 승리”와 “3명 미만 → 경기 중단(공동 순위)” 중 무엇이 우선인지 정의 필요 — 구현 백로그.
- 해체반의 💣 요청 거부 응답은 해당 요청자에게만 보내야 함(구현 주의).
