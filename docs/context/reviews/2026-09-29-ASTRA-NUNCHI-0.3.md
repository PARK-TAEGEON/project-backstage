## 비치명 지적과 처리
1. 도중에 3명으로 줄 때 진행 여부 미정 → 4명 미만이면 남은 라운드 없이 게임 종료로 정하고 코드 반영.
2. 판정 규약 절에 10ms 문구 잔존 → 1ms(0.001초)로 수정.
3. 시간 초과(전원 탈락)·연결 끊김(라운드 계속)이 “걸리면 종료” 규칙의 예외 → 스펙에 예외로 명시.
