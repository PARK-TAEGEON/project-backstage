## 치명 (수정함)
- **C-1 BAN 소개 단계 이탈 시 예외 → 게임 전체 무효:** 소개 중 그룹 사회자가 아직 없는데 그룹 조기 종료가 사회자를 멈추려다 예외. 7명 경기에서는 다른 조까지 무효가 됨. → 사회자를 없을 수 있는 값으로 바꾸고, 먼저 끝난 그룹에는 사회자를 만들지 않음. 회귀 테스트 2개 추가.

## 이상 없음으로 본 것
- WORD: 자기 단어·단어 득점은 본인 view에만, 라운드 중 합계는 지난 라운드까지만 공개, 챌린지 성공 때만 대상 단어 공개, 마감 경계, 3명 미만 종료.
- BAN: 자기 금지어는 view·공지·채팅 기록·재접속 어디에도 본인에게 안 감. 소개·진행 중 채팅은 항상 같은 조에게만. 적발→챌린지 대기→입막힘 전이, 라운드 종료 시 대기 중 챌린지는 “안 함”으로 확정, 재편성은 전체 종료 뒤 한 번.
- 사회자: 비밀 단어가 든 문장 제외, 게임 종료 뒤 타이머 정리.

## 비치명 지적과 처리
1. WORD 득점 때 모두에게 화면 갱신이 가서 갱신 시점으로 득점 메시지를 추정할 수 있음 → 본인에게만 갱신(`updatePlayer`) 추가.
2. 먼저 끝난 조에 사회자가 계속 돔 → C-1 수정으로 해결.
3. room 테스트 간헐 실패(공동 순위 안의 순서가 id 모양에 따라 바뀜, 이번 변경과 무관) → 정렬해서 비교.
4. BAN 적발 공지가 1ms 늦게 나감 (라운드 종료 직전이면 공개 뒤에 올 수 있음, 누출 없음) → 백로그.
5. 공개 화면에 적발 직전 대화 몇 줄 [제안] 미구현 → 백로그.
6. 사회자 문장에도 같은 정규화 적용 → 수정.
