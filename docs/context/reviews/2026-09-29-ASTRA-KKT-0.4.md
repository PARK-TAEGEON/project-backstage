# ASTRA — KKT 0.4 변경분 치명 문제 확인

- 일자: 2026-09-29 / 검토자: 별도 리뷰어(서브에이전트) / 기준: 05-QA-PIPELINE (치명만)
- 대상: KKT 0.3→0.4 (DEC-17) — 틀린 단어 재시도, 차례 시간 10초→최소 3초 감소, 한 차례 안 0.3초 연타 방지. 스펙·서버·웹·테스트
- **판정: pass (치명 0건)**

## 확인한 것
- 몇 번을 틀려도 시간 초과 타이머는 유지 → 차례는 반드시 끝남. 타이머는 통과·탈락·종료 때만 지워짐.
- 제출 잠금은 거절 횟수가 키에 들어 있어 거절마다 풀리고, 서버가 무시한 제출도 1초 뒤 풀림 → 입력 불가 없음.
- 화면의 차례 시간과 서버 판정 시간 일치. 경기 전체 단어 수 기준으로 줄어듦. 연타 방지는 차례마다 초기화.

## 비치명 지적과 처리
1. 응답이 1초보다 늦으면 입력칸이 안 비워짐 → 내 단어가 거절되면 항상 비우도록 수정.
2. 재시도 효과음이 빠질 수 있음 → 차례+거절 횟수 키로 울리도록 수정.
3. 차례 도중 음소거를 풀면 박자가 안 울림 → 남은 박자부터 다시 예약하도록 수정.
4. 입력 길이 제한(웹 10자, 서버 20자) 불일치 → 판정 영향 없음, 유지.
5. 테스트 보강(여러 번 거절 뒤 시간 초과, 라운드가 바뀌어도 시간 계속 감소) → 추가.
