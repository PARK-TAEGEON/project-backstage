# 9. 공통 판정·진행 규약 (엔진)

ASTRA 1차 검수(2026-09-29, [리뷰](reviews/2026-09-29-ASTRA-BATCH-01.md))에서 여러 게임에 공통으로 걸린 정의 누락을 한곳에 모았다. 게임 스펙은 이 규약을 따르고, 다를 때만 스펙에 예외를 적는다. 전부 **[기본값·가설]**이며 DEC-12(proposed)로 기록했다.

## 1. 판정 시계와 순서
- 모든 판정은 **서버 접수 시각** 기준. 방마다 판정자 하나, 단조 증가 시계 하나를 쓴다. 표시용 반올림 값으로 판정하지 않는다.
- 같은 시각의 요청은 서버가 매기는 **접수 번호** 순으로 처리한다.
- 마감이 있는 구간은 **`시작 ≤ 접수 < 마감`**. 마감과 같은 시각은 마감 후로 본다.
- 마감 전에 접수된 요청은 판정 계산이 마감 뒤에 끝나도 유효하다.

## 2. 한 번만 적용
- 모든 제출(채팅 득점, 챌린지, 투표, 단어, 숫자)에 **요청 ID**를 붙이고, 같은 ID의 결과는 한 번만 적용한다. 재전송은 무시한다.
- 점수 변경과 상태 변경(잠금, 입막힘, 탈락)은 **한 번에 함께 확정**한다.
- 이미 무효가 된 대상에 대한 요청(잠긴 대상 챌린지, 탈락자 제출 등)은 무효 처리하고 감점하지 않는다. 게임 스펙이 따로 정한 경우는 예외.

## 3. 종료 → 집계 → 공개 순서
1. 마감 시각 도달
2. 마감 전 접수된 요청 처리, **미완료 판정은 “안 함”으로 확정** (예: 금지어 챌린지)
3. 결과 잠금 (이후 요청은 무효)
4. 집계 → 공개(Reveal) → 다음 라운드 또는 결과 화면

## 4. 이탈·재접속·인원 감소 (OPEN-10 부분 해소)
- **이탈 확정:** 연결이 끊긴 뒤 [기본값·가설: 10초] 안에 돌아오지 않으면 이탈로 확정한다. 확정 전에는 참가 중으로 본다.
- **점수 유지:** 이탈자의 점수는 유지된다.
- **이번 라운드 자격:** 이탈자는 **해당 라운드가 끝날 때까지 상대의 대상 자격을 유지**한다 (챌린지·지목 대상). 이탈로 불리한 상황을 피할 수 없게 한다.
- **재접속:** 같은 라운드에 돌아오면 그 사람의 상태(비밀 단어, 점수, 잠금, 입막힘, 마지막 득점 시각, 남은 기한)를 그대로 복원한다. 게임이 “재접속해도 복귀 불가”로 정한 경우(쿵쿵따, 눈치게임)는 그 규칙을 따른다.
- **최소 인원 미만:** 실제 참가자가 게임의 최소 인원(기본 3명, 포브스는 4명) 미만이 되면 진행 중인 라운드는 게임 규칙대로 마치고, **새 라운드는 시작하지 않는다.** 누적 결과로 경기를 끝낸다.
- **전원 이탈:** 승자를 만들지 않고 “경기 중단”으로 기록한다.

## 5. 비밀 정보 전달
- 비밀 정보는 화면에서 가리는 것이 아니라 **받을 권한이 있는 사람에게만 서버가 보낸다.** 재접속용 상태 응답에도 같은 권한을 적용한다.
  - 단어 말하기: 자기 단어는 본인에게만.
  - 금지어: 자기 금지어는 **본인에게 절대 보내지 않는다**. 같은 그룹의 다른 사람 금지어만 보낸다.
- 그룹이 바뀌면 이전 그룹 채널 구독을 끊고 새로 권한을 계산한다.

## 6. AI 호출
- **AI에는 비밀 정보를 보내지 않는다.** 사회자(물꼬 트기)는 배정 단어·금지어를 모르는 상태로 문장을 만든다. 모르는 단어는 흘릴 수 없다.
- 생성된 문장과 대체 문장 모두 서버에서 배정 단어 포함 여부를 검사한다. 통과하는 문장이 없으면 그 회차 발화를 생략한다.
- 호출 제한 시간 **3초, 재시도 0회**. 늦게 온 응답은 버린다.
- 출력은 개수·형식·규칙을 모두 검증한 뒤 한꺼번에 적용한다. 대체 목록도 같은 검증을 거친다. 둘 다 부족하면 “시작 실패”를 명시적으로 알린다.

## 7. 문자열 정규화
- 배정 단어, 채팅, 추측, 제출 단어 모두 **같은 함수**로 정규화한다: 유니코드 NFC, 앞뒤 공백 제거.
- 판정 규칙(글자열 포함, 정확히 일치, 사전 대조)은 정규화한 값에 게임 스펙대로 적용한다. 정규화가 확정 규칙을 넓히지 않는다 (예: `근디`는 여전히 `근데`가 아니다).

## 8. 판정 데이터 버전
- 단어 목록, 사전 스냅샷, 두음법칙 변환표, 질문 덱은 **버전을 붙여 고정**하고, 리뷰·테스트 기록에 버전을 남긴다.
