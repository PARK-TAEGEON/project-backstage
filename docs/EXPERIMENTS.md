# Experiments

아직 실제 플레이테스트를 수행하지 않았다. UI 확인은 재미 검증 데이터로 계산하지 않는다.

## 첫 테스트 제안
Secret Director로 친구 4–6명, 8분, 중간 개입 1회. 끝난 직후 “바로 한 판 더?”를 묻는다. 완주율과 재게임 클릭, 초대/공유 행동을 기록하고 관찰자 메모를 함께 남긴다.

## 기록 템플릿
- Experiment: 날짜 / 게임 / 버전 또는 commit
- Hypothesis:
- Players: 인원, 기존 친밀도 (실명 제외)
- Observed behavior:
- Funny moments: 동의받은 익명 요약
- Dead moments:
- Problems:
- Completion: game_completed / game_started
- Replay: 완료 세션 중 재게임 클릭이 발생한 세션 비율
- Invite: invite_link_copied 수 (실제 초대 수락과 구분)
- Share: result_shared 수
- Next change: 한 번에 바꿀 변수와 예상 효과

미완료/중복 세션을 분모에 어떻게 처리했는지도 기록한다. 소규모 첫 표본은 통계적 결론보다 다음 실험을 정하는 데 사용한다.
