|---|---|
| 원본 | 국립국어원 **표준국어대사전**(빌드 2026-06-05) + **우리말샘**(빌드 2026-06-02) XML 내려받기본 |
| 가져온 곳 | https://github.com/spellcheck-ko/korean-dict-nikl (커밋 `42c0d01`, 스크립트에 고정) |
| 구성 | 표준 97,149 + 우리말샘에만 있는 100,394 |
| 스냅샷 버전 | `stdict-2026-06-05+opendict-2026-06-02` — 서버가 게임 화면에 이 값을 표시한다 |
| 만드는 법 | `python3 scripts/build-kkt-dict.py apps/server/dict/kkt-3syl.tsv.gz` (원본을 하나씩 내려받아 처리, 약 3분. 정규화·범위 규칙은 스크립트 주석) |
| 라이선스 | **CC BY-SA 2.0 KR** (저작자표시-동일조건변경허락). 이 파일(가공 데이터)도 같은 조건으로 배포한다. 출처: 국립국어원 표준국어대사전·우리말샘 |

- 게임 코드의 라이선스와는 별개다. 이 폴더의 데이터 파일에만 CC BY-SA가 적용된다.
- 사전 예문은 오픈 라이선스가 아니라서 넣지 않았다 (단어와 뜻풀이만).
- 게임 화면 하단에 출처를 표시한다. 우리말샘에만 있는 단어는 뜻 앞에 〔우리말샘〕.
- 두 사전 모두에 없는 말: 상표·서비스 이름(유튜브, 인스타, 아이폰), 높임 접미사가 붙은 말(사장님), 비표준 표기(피씨방 → 피시방).
